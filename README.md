# lingo-agent

An open-source AI English tutor agent: long-term memory, an adaptive learning engine, CEFR assessment, FSRS spaced repetition, graded news reading, grammar GraphRAG, and voice conversation.

开源 AI 英语私教 Agent：用户长期记忆、自适应学习引擎、CEFR 能力评估、FSRS 背单词、分级新闻阅读、语法 GraphRAG、语音对话。

**Stack:** FastAPI · LangChain / LangGraph · OpenTelemetry · PostgreSQL + pgvector · Neo4j · Next.js

> 🚧 Early stage. See [docs/PLAN.md](docs/PLAN.md) for the design and [docs/PROGRESS.md](docs/PROGRESS.md) for status.
