# 演示脚本

[English](demo.en.md)

用一个已经学了两周左右的演示账号，在 5–10 分钟里走一遍 Lingo Agent 的主要功能。每一步都写了**说什么**、**点什么**和**应该看到什么**。“应该看到”这几条也可以当作端到端走查的清单，逐项勾选。

## 准备（演示前做一次）

1. 按 README 的“快速开始”起好服务并导入词表：`make env`、`make up`、`make vocab-import`、`make sentences-import`。
2. 生成演示账号：

   ```bash
   make demo-seed ARGS='--password 你的演示密码'           # 中文讲解
   make demo-seed ARGS='--password 你的演示密码 --lang en' # 英文讲解
   ```

   它会创建 `demo@lingo.example.com`；如果已经存在，就连同它的全部数据删掉重建。其他账号不会被读取或改动，也不调用任何模型。不写 `--password` 时会随机生成一个并打印出来。
3. 用演示账号登录，在 **设置 → 模型连接** 里添加一个连接（演示账号默认没有模型）。也可以用主账号发邀请链接，让演示账号加入后借用主账号的模型。
4. 可选：如果要演示打电话，需要配置一个支持实时语音的连接；跟读的评分则需要语音转文字或发音评测。不配置这些也能演示，到第 7 步时跳过即可。

**演示账号的设定**：小林，在一家旅行 App 公司做产品经理，今年晚些时候要去新加坡参加会议并做一个简短的发言。喜欢老电影、徒步和咖啡，每天学 20 分钟。他总把现在完成时和一般过去时混用，希望讲解主要用中文、例句用英文。账号里有大约两周的学习记录：入学测、每天的单词复习、两组语法练习、一篇写作、一篇阅读、一次口语练习和一次诊断。所有分数都是真实的引擎算出来的，只是日期放在了过去。**账号里没有聊天记录**，对话留到演示时用真实模型现场进行。

## 演示流程

### 1. 看板（约 1 分钟）

- **说**：“这是学了两周之后的样子。等级和词汇量来自入学测，之后会随着学习更新。”
- **点**：侧栏 **看板**。
- **应该看到**：
  - [ ] CEFR 等级 **B1**，估计词汇量约 3,500 词，连续学习 10 天，以及今日待复习的词数。
  - [ ] **今天的计划**：复习、语法练习、新词等几项，每项标了大约几分钟，合计接近每天 20 分钟。可以加减或开关，然后点 **确认计划**；确认之后，完成的项会自动勾掉。
  - [ ] 往下有学习打卡日历、语法掌握和常错语法点。

### 2. 学习者模型（约 1 分钟）

- **说**：“掌握度不是让大模型打分，而是由 BKT/Elo 根据每一条证据计算。每个数字都能点开看依据。”
- **点**：侧栏 **学习者模型**，点开“现在完成时与一般过去时的区别”。
- **应该看到**：
  - [ ] **语法掌握度**：“现在完成时与一般过去时的区别”是薄弱项，“形容词比较级”正在巩固，“be going to 表示计划和有依据的预测”已学会。
  - [ ] 点开一项，可以看到错误次数、用对次数，以及每条证据来自入学测、练习还是对话；每条都可以删除，删除后掌握度会重新计算。
  - [ ] **助手的诊断**：指出反复出错背后可能的原因，可以展开看引用的错句；如果诊断不对，可以点“这次诊断不对”删掉。
  - [ ] **技能估计**、**跟读记录**、**我的 AI 用量**。
- **再点**：侧栏 **记忆**。
- **应该看到**：
  - [ ] **你的画像**和**助手记住的事**（旅行 App 产品经理、新加坡会议、周末去杭州周边徒步、正在看《罗马假日》……）。每一条都可以编辑和删除。

### 3. 对话（约 2 分钟）

- **说**：“我们故意犯他常犯的错，看助手怎么处理。”
- **点**：侧栏 **对话**，依次发送：
  1. `I have been to Hangzhou last month with my family.`
  2. `We walked around West Lake and I have tried the Longjing tea.`
- **应该看到**：
  - [ ] 助手自然地接着聊，同时指出“last month”这类明确的过去时间要用一般过去时，并用中文讲解（这是记忆里的偏好）。
  - [ ] 回复里会提到它记得的事，比如徒步或者新加坡的会议。
  - [ ] 回复下方有一行 **JOJO做了什么**：读取了几条记忆、标记了几个语法错误等。展开可以看到具体是哪几条，并可跳到“管理记忆”或学习者模型。
  - [ ] 回到 **学习者模型**，刚才的错误已经作为新证据出现在“现在完成时与一般过去时的区别”下面。（记忆整理在后台进行，不会拖慢回复，可能要等几秒钟。）

- **再演示工作区**（约 1 分钟）：
  - **点**：把一篇 800 个字符以上（约 150 词）的英文文章粘贴进输入框，点提示里的 **在工作区精读**。
  - **应该看到**：
    - [ ] 对话收窄，右侧打开工作区，地址栏多了 `?w=`；输入框里的长文被拿走。
    - [ ] 切到 **对照**，每段下方出现中文译文；打开 **点句分析** 点一句，句子下方展开主干、从句、短语和句意。
    - [ ] 选中一段，点 **问 JOJO**，输入框里出现 `>` 引用，问一句“这里的 adopt 是什么意思？”，助手结合文档回答。
  - **点**：发一段 20 词以上、有错的短文，比如 `My sister like music very much. She play the piano every day after school and she want to be a teacher in the future.`，再说“帮我在工作区打开改一改”。
  - **应该看到**：
    - [ ] 助手打开写作文档，并给出逐条修改建议（按词标出差异）；接受一条、不用一条，版本号跟着变。
    - [ ] **版本** 里能看到每一版，点旧版本 **回到这个版本** 会存成新的一版。

### 4. 背单词（约 1 分钟）

- **说**：“复习时间由 FSRS 调度。”
- **点**：侧栏 **背单词** → **开始**，复习几张卡片。
- **应该看到**：
  - [ ] 今天要复习几个词，还剩多少新词；当前词书是 Oxford 3000。
  - [ ] 卡片上有音标、释义，以及 Tatoeba 例句（带中文翻译）；点击例句旁的麦克风可以跟读。
  - [ ] 回到 **看板**，今日待复习的数字变少了。

### 5. 阅读（约 1 分钟）

- **说**：“新闻会按学习者的等级改写，并附上理解题。”
- **点**：侧栏 **阅读**，打开 “Volunteers plant a million trees along an old railway”。
- **应该看到**：
  - [ ] B1 改写版 “A million new trees on an old railway”，可以切换到原文。
  - [ ] 今天该复习的词用黄色高亮，超出等级的词有虚下划线。
  - [ ] 文末有理解题和原文依据；可以点 **就这篇文章问助手**。

### 6. 语法练习（约 1 分钟）

- **说**：“题目由一个模型来出，再由另一个模型审核，没通过的题会重写或者从题库补。”
- **点**：侧栏 **语法练习** → **开始一组**，做两三题。
- **应该看到**：
  - [ ] 出题时会显示“正在出题 / 正在审题”等阶段。题目集中在薄弱点上，中间穿插已经掌握的点。
  - [ ] 每题答完立刻有讲解；“改写自己说错过的句子”这类题用的是他真实犯过的错。
  - [ ] **最近的练习**里能看到之前做过的两组。做完一组后，结果页会显示每个语法点掌握度的变化。

### 7. 口语和跟读（约 1–2 分钟）

- **点**：侧栏 **口语**，打开“练过的”里那次自我介绍。
- **应该看到**：
  - [ ] 小结里有：说得好的地方、说错的和改法、更地道的说法、下次可以试试（可以 **加入生词本**），以及 **再练一次**。
- **可选（需要实时语音连接）**：点 **打电话**，选“自我介绍”情景，说一两句，然后问助手一个生词的意思，并请它把这个词加进生词本。
  - [ ] 通话里会出现“查了这个词”“加入生词本”的工具记录，加入的词可以撤销。
  - [ ] 助手觉得可以结束时，会弹出“要挂断吗？”。挂断后可以看到转写和小结。
- **可选（跟读）**：在对话页助手的回复旁点麦克风读一遍。
  - [ ] 这次跟读出现在 **学习者模型 → 跟读记录** 中；没有发音评测服务时，标为“粗略”。

### 8. 我的助手和桌宠（约 30 秒）

- **点**：侧栏 **我的助手**。
- **应该看到**：
  - [ ] 可以调整外观（名字、服装、毛色、动画）、开关桌宠，以及设置对话模型。
  - [ ] 每个页面右下角都有桌宠，点它可以就地和助手聊天。

### 9. 设置：用量和成员（约 1 分钟）

- **说**：“模型的 key 由使用者自己配置，加密后存在数据库里。所有的 AI 调用都有记录。”
- **点**：**设置 → 用量**，再到 **设置 → 成员**。
- **应该看到**：
  - [ ] 用量：总计、每日图表，以及按用途和模型拆分的调用次数和 token 数（刚才的演示也会出现在里面）；填入单价之后，会估算费用。
  - [ ] 成员：可以生成邀请链接，按成员设置每天和每月的额度（留空表示不限，0 表示关闭）。成员看不到你的 key，你也只能看到他们的用量。
  - [ ] 每个会调用模型的入口都有 AI 标记，点开前就能知道这里会用到 AI，以及每次大约消耗多少 token。

## 新账号全流程走查

演示账号跳过了注册和入学测。要完整走查一遍（PLAN “验证方式”中的端到端一条），可以另外注册一个新账号，按下面的顺序走：

- [ ] 注册后先走配置引导（ADR 0042）：称呼和语言、接入模型、学习目标、助手名字；模型一步可以粘贴 key 或用邀请码，跳过要二次确认；最后点“开始学习”进入看板，刷新不再弹出。
- [ ] **入学测**（约 10 分钟）：结果页给出等级和估计词汇量，可以就地和助手讨论结果。
- [ ] **对话**：说一件关于自己的事，比如工作或爱好。回复下方“JOJO做了什么”里显示记下了 1 条或几条记忆，**记忆**页里也能看到。
- [ ] 新建一个会话，问助手“你还记得我做什么工作吗？”：它应该能引用上一个会话里记下的事。
- [ ] **背单词**：选一本词书，学几个新词并复习。
- [ ] **阅读**：打开一篇文章，等改写版生成后做理解题。
- [ ] **跟读**：点段落旁的麦克风读一遍，记录出现在“学习者模型 → 跟读记录”里。
- [ ] **工作区**：在对话里粘贴一段长文，在工作区里精读（对照、点句分析、选中问助手）；再把一篇作文在工作区打开，请助手改稿，逐条接受或不用，最后回到第 1 版；缩到手机宽度看“对话 / 工作区”两个标签。

## 重置

再运行一次 `make demo-seed`，演示账号就会恢复原样（演示时产生的对话和记录都会被删掉）。
