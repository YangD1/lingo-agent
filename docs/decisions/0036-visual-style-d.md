# 0036 · 视觉风格 D：不透明卡片 + 固定层毛玻璃

- **状态**：已采纳（2026-10-14，任务 73；用户在预览页四套方案里选了 D，Q73a–h 全部按推荐确认）
- **日期**：2026-10-14
- **影响**：修订 ADR 0019 的“卡片不加阴影”；`globals.css` 新增阴影、毛玻璃、页面底色 token 和 `glass` / `glass-pop` 工具类；原生 `<select>` 全部换成 base-ui Select（任务 73.2）。预览页存档在 `docs/design/lingo-style-d/preview.html`。

## 背景
- 功能做完后回看 22 张截图：全站都是 1px 描边、不加阴影的扁平卡片，层次弱；原生下拉在各浏览器长得不一样，弹出列表也没法配合风格。
- 用户希望整体更现代，提到了拟物和苹果的液态玻璃。
- 预览页给了四套方案：A 温暖扁平 + 柔和阴影、B 全站液态玻璃、C 柔和拟物、D 混合。

## 决定
- **D 混合**：读内容的地方（卡片、消息气泡、表格）保持不透明，加一层柔和投影（`--shadow-card`）；固定在页面上的层（侧栏、手机标签栏、聊天输入框）和浮在页面上的层（下拉、弹出层、单词气泡）用毛玻璃。
- **毛玻璃只给少数层**：`glass` 用于固定层，`glass-pop` 用于浮层（多一层 `--shadow-pop`）。列表里的卡片一律不用 `backdrop-filter`，因为每帧都要重算模糊，低端手机滚动会卡。
- **退路**：系统开了“减少透明度”（`prefers-reduced-transparency: reduce`），或者浏览器不支持 `backdrop-filter`，`--glass` 退回不透明的 `--popover`。
- **页面底色**：在 `body::before` 放两块很淡的角落色（左上珊瑚 `--tint-1`、右下靛蓝 `--tint-2`），让玻璃层有东西可以“磨”。用 `position: fixed` 的层，滚动时不重绘。
- **按钮和输入框**：实心按钮加 `--shadow-button`（投影 + 顶部高光），输入框、下拉触发器、描边按钮加很浅的 `--shadow-field`。
- **品牌色不变**：珊瑚主色、logo 原色、靛蓝 AI 色、CEFR 和热力图色阶都沿用 ADR 0019，只加阴影和透明度相关的 token。
- **深色模式一起做**：每个新 token 在 `.dark` 里都有对应值；深色下阴影更重、玻璃描边改成淡白。
- **下拉**：base-ui Select，列表在触发器下方弹出，可带色点和右侧数量。三个选项以内、位置够宽的改用 `Segmented`。

## 取舍
- 玻璃感比全站玻璃（B）克制，第一眼冲击力弱一些；换来的是阅读、写作页的文字对比度不变，滚动性能可控。
- 柔和阴影让信息很密的页面（设置、学习者模型）比原来稍“重”一点，改各页时按需用 `shadow-none` 收回。
- 毛玻璃在 Firefox 旧版本和部分国产浏览器内核上可能不生效，会退回不透明，样子和 A 方案相同，不影响使用。
