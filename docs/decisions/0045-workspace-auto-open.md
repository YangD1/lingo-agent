# 0045 · 助手按需自动打开工作区，学习者用自然语言收起或关掉自动打开

- **状态**：已采纳（2026-10-16，任务 87；Q87a–c 按推荐确认）
- **日期**：2026-10-16
- **影响**：补充 ADR 0043 §6。`tutor_profiles` 新增 `workspace_auto_open`；助手卡片新增 `workspace_closed`、`workspace_auto` 两种；助手新增工具 `close_workspace`、`set_workspace_auto_open`；writing_coach 批改后由代码打开写作文档；`tutor_tools.md` 新增工作区一节。

## 背景
- ADR 0043 已经有 `open_workspace`，前端收到它的卡片会自动在右侧打开。但实际上助手从来没调用过它（库里助手建的文档是 0），学习者只能自己点。原因有三个：
  - `tutor_tools.md` 没介绍工作区工具，模型只看得到 schema；
  - 同一份提示要求"只在学习者要求或同意时用，不确定先问"；
  - 60 词以上、像作文的消息会转给 writing_coach，它不带工具。
- 学习者希望：助手判断需要就直接打开；不喜欢时用一句话就能收起，或者以后都不要自动打开；工作区和对话的联动保留（Q87a）。

## 决定

### 1. 什么时候自动打开（`tutor_tools.md` 工作区一节）
- 学习者贴了一整篇英文（多段或长段落），想读懂、翻译或分析：开**精读**，来源 `last_message`。
- 学习者要写或改一篇较长的东西（作文、邮件、自我介绍），或者想照着助手给的提纲自己写：开**写作**，来源是刚发的那篇（`last_message`）或空白（`blank`）。
- 短句、单个单词、一两句话的问题都不开。这段对话里已经为同一段文字开过文档（卡片记录里有），就不再开。
- 工作区可以撤销、不花 token、不改学习数据（ADR 0043 取舍），所以偏好开着时**不用先问**，打开后一句话说明即可。
- 偏好关着时，提示改为"只在学习者明确要求时打开"，工具仍然可以用。

### 2. 用自然语言收起：`close_workspace`
- 不带参数。学习者说"关掉右边""先不用工作区"时调用。只把面板收起来，**不删文档**；卡片 `workspace_closed`（`info`）写"收起了工作区"，上面有"重新打开"（打开这段对话最近的文档）。
- 前端只在实时收到这张卡片时收起面板；翻历史时不执行收起。
- 幂等：同一个 tool call id 只出一张卡片。

### 3. 用自然语言关掉自动打开：`set_workspace_auto_open(on)`，存成长期偏好（Q87c）
- `tutor_profiles.workspace_auto_open`，默认 `true`，和"桌宠""每天开场"放在一起，助手设置页有开关。
- 学习者说"以后别自动打开工作区"（或者"还是自动打开吧"）时调用，**直接生效**，因为是学习者自己提的要求。卡片 `workspace_auto`（`applied`）写明现在的状态，"撤销"会恢复调用前的值。这个值也能在设置页改回来。
- 值和现在一样时也出卡片，结果告诉助手"本来就是这样"。同一个 tool call id 只改一次（幂等）。
- 关掉自动打开的同时通常也希望收起，提示要求两个工具一起调用。

### 4. 作文转给 writing_coach 时（Q87b）
- writing_coach 不加工具（ADR 0043 §6 不变）。偏好开着时，批改那一轮由**代码**把这篇作文建成写作文档（来源 `writing`，作者记为助手），再发一张 `workspace` 卡片，前端照常自动打开；"这是一篇作文"由已有的 `route` 分类器判断。
- 同一篇提交只建一份（按提交 id 查已有文档）。偏好关着时不建，批改卡片上的"在工作区改稿"照旧可用。
- 活动记录新增 `workspace_opened` 一步（“JOJO做了什么”里显示打开了哪份文档）。

### 5. 联动不变（Q87a）
- 每轮把当前打开的文档作为数据交给助手、选中文字"问 JOJO"、助手改稿逐处确认（ADR 0043 §4–§6）都保持不变。

## 公示（ADR 0013、0014）
- 两个新工具、writing_coach 批改后的自动打开都写进 `docs/agent-tools.md`；"JOJO做了什么"里各记一行。
- 没有新增模型调用：工具算在 `chat_message` 的 `chat_tools` 里，`features.yaml` 的说明里补一句。

## 取舍
- **直接打开 vs 先问**：先问每次都要多一轮对话，而打开文档本身没有代价、可以撤销，学习者也能一句话关掉，所以直接打开。
- **偏好存在助手设置里，不存成记忆**：记忆由异步反思抽取，生效时间不确定，助手也可能误读；开关是确定的值，设置页看得到、改得了。
- **writing_coach 用代码打开，而不是给它加工具**：作文批改那一轮已经确定是作文，再让模型判断一次只会多花 token、多一种失败方式。
