# 0054 · 课程会话和常规会话分开引导：越界去对应的课、开场看状态、先分清意图

- **状态**：已采纳（2026-10-17，任务 98；用户按推荐确认 Q98a–d）
- **日期**：2026-10-17
- **影响**：修订 ADR 0044 §5（课程对话的开场和越界）、ADR 0015（新工具 `suggest_lesson`、新卡片 `lesson`）、ADR 0052 §1（普通对话的“学到哪”多一行引擎建议）；`tutor_cards.kind` 加 `lesson`（迁移）；`tutor_system.md`“以问题结尾”的规则收窄；`docs/agent-tools.md` 同步。

## 背景
用户要求两种会话分开对待：课程会话一开始就该知道主题、水平、该做什么，直接讲、直接出题，问到别的语法点就让他去对应那一课；常规会话靠长期记忆知道学到哪、掌握到什么程度、下一步做什么，并先分清学习者是问了问题（解答），还是让我们决定学什么（按记忆和近况直接给下一步）。

查代码和开发库：

1. **上下文其实都有**。课程对话每轮带这一课的资料（语法点、状态、前置课、本人错句、测验记录、下一课）和画像 / 事实 / 学到哪；普通对话带画像 / 事实 / 学到哪 / 摘要。上下文加载 p90 不到 0.1 秒，出题的题目也已经用了水平和事实。
2. **课程对话没说越界怎么办**。`suggest_practice` 在课程范围外被拒，`suggest_link course` 只到课程页，没有能打开某一课的卡。
3. **课程开场固定**：先问一个回忆问题（紧接着就出理解检查，问题没人答），再讲规则、出检查，不看这一课已有的测验记录。
4. **`tutor_system.md` 要求每条回复以问题结尾**，和“答完就停”冲突；普通对话没有“先分清意图”的规则。
5. **普通对话只知道当前课**，引擎建议（`advice/candidates.py`）只给今日 / 规划对话。

## 决定

### 1. 新工具 `suggest_lesson`，卡片 `lesson`（Q98a、Q98b）
- 参数：`kc_id`（语法点 id）或 `topic`（名字，复用 `give_quiz` 的匹配，ADR 0046 §1）。不受对话范围限制：它本来就是把学习者带出这一课用的。
- 代码按学习者的课程（`adaptive/course.py`）定打开哪一课：目标课没锁就是它；**锁着时打开最早一节没过的前置课**（目标课所有直接和间接前置课里，状态是“学习中 / 可开始”、课号最小的那节），工具结果和卡片都写明“先学第 M 课，再学第 N 课”。
- 在课程对话里指向正在上的这一课时拒绝，让私教直接在这里教。
- 补充（98.5 冒烟，用户确认）：两个参数都不给时，课程对话取本课之后第一节没过的课，普通对话取课程的当前课（qwen-plus 常不带参数调用，同任务 96 的 `give_quiz`）；名字匹配到几个得分并列最高的语法点时（如“现在完成时”分在几课里），取课程里最靠前的那一课，工具结果写明，不再交回模型选。工具结果写明卡片只是指路、学习者点了才进那一课，这里不开讲（冒烟里私教出卡后说“你已经进入第一课”就开讲了）。
- 卡片参数 `kc_id`（要打开的课）、`number`（课号）、`asked_kc_id`（锁着时原本问的那一课）；没有副作用，状态 `info`。点击“开始 / 继续这一课”走 `POST /course/lessons/{kc_id}`，和课程页一样开始或继续那一课的对话（会触发 `lesson_start` 的开场，按钮挂 `AiBadge`）。
- 课程对话的越界规则（`lesson.md`）：学习者问到别的语法点时，用一句话答，让他不悬着；然后出这张卡说“这在第 N 课专门练”，再回到本课。普通对话也能用这张卡，当学习者想系统学某个语法点时。

### 2. 课程开场按状态（98.2）
- 没开始：三到五句讲核心规则，配一两个例子，然后出理解检查。
- 学过没过：一句话点出上次测验错在哪，针对那里讲，再出理解检查。
- 待复习：一句话说明是复习，直接出过关测验。
- 去掉不等回答的回忆问题。状态由代码给（这一课的资料里已有），模型不自己判断。

### 3. 普通对话先分清意图（98.3，Q98d）
- 只给普通对话（不是课程 / 练习 / 今日 / 规划 / 阅读 / 口语）加一段规则：
  - 学习者问了问题：完整解答，答完就停，最多提一句可以接着做的事，不硬加追问；
  - 让我们决定（“我该学什么”“你定”“随便”）：从“学到哪 / 下一步”里挑一个具体的下一步，说明为什么，出卡，不反问他想学什么；
  - 闲聊：照常聊，纠错。
- `tutor_system.md` 的“以问题结尾”改成：闲聊时以问题或小任务结尾；回答问题后不硬加问题。课程和练习有自己的规则，以具体任务（造句、做卡）结尾。

### 4. 普通对话的“下一步”（98.4，Q98c）
- “学到哪”（ADR 0052 §1）在普通对话里多 1–2 条引擎建议，由 `advice/candidates.py` 纯代码算出，不调模型；每条带能直接出卡的语法点 id 或页面。今日 / 规划对话已有完整建议，不重复。

## 公示（ADR 0013、0014）
- `docs/agent-tools.md` 登记 `suggest_lesson`；卡片在对话里可见，学习者看得到私教做了什么。
- `suggest_lesson` 本身不调模型。点卡开始一课触发的开场已在 `features.yaml` 的 `lesson_start` 登记，卡片按钮挂同一个 `AiBadge`。

## 取舍
- **不在课程对话里把别的语法点讲透**：讲透会把这一课拖散，学习者也拿不到那一课的测验和掌握度记账。一句话答是为了不让他觉得被拒绝。
- **锁着时不直接打开目标课**：课程页对锁着的课只给“直接测验”，不开讲；卡片顺着前置关系走，和课程页一致。想跳过的学习者仍可在课程页直接测验。
- **引擎建议放进上下文，不做成按需工具**：每轮多几十个 token，换来“你定”时不用多一轮工具调用。
