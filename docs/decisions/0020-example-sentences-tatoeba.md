# 0020 · 复习卡片例句：Tatoeba 真例句 + 按需 AI 例句

- **状态**：已采纳（2026-10-02，任务 28，Q28a–c 按推荐确认）
- **日期**：2026-10-02
- **影响**：新增 `word_sentences` 表和 `make sentences-import`；新增依赖 `opencc-python-reimplemented`（纯 Python，约 1.2 MB，只在导入时加载；放在正式依赖里，宿主机没有 uv 时也能在后端容器里导入）；复习卡片、生词本的单词带 `sentences`；`word_examples`（ADR 0017 §3）多一个入口：复习卡片。

## 背景
用户反馈复习卡片来源只有 ECDICT、没有例句。ECDICT（ADR 0011）的 `definition` 本身是 WordNet / Webster 1913 合并来的，但没有例句。AI 例句（`word_examples`）已经有了，只在聊天单词气泡里用，而且每个词都要调用模型。

核实结果（2026-10-02）：
- **Tatoeba**：志愿者写的句子和人工翻译，下载文件是 CC BY 2.0 FR（注明来自 Tatoeba、附链接、写明许可即可），部分句子另有 CC0。官方按语言拆的导出每周更新，没有带版本号的地址：`per_language/eng/eng_sentences.tsv.bz2`（24.9 MB）、`per_language/cmn/cmn_sentences.tsv.bz2`（1.3 MB）、`per_language/cmn/cmn-eng_links.tsv.bz2`（0.5 MB）。2026-09-26 的导出：中文句 89,102 条、中英链接 78,222 条，其中有中文翻译的英文句 72,696 条，4–20 个词的 65,335 条。中文里约 45% 是繁体。
- **按词形（`exchange` 里的变形）匹配到现有 38,243 个词后的覆盖率**（至少 1 句 / 至少 2 句）：中考 99% / 98%，高考 93% / 88%，CET4 90% / 79%，考研 83% / 68%，CET6 77% / 60%，雅思 73% / 58%，托福 53% / 37%，GRE 32% / 18%。
- **其他来源**：Open English WordNet（CC BY 4.0）的例子多是短语，补充价值低；Wiktionary（kaikki.org 原始数据压缩后 2.8 GB，CC BY-SA / GFDL）太重，等做词根词缀时再看。柯林斯、牛津、朗文不能用于开源项目。
- **繁简转换**：`opencc-python-reimplemented` 0.1.7，Apache 2.0，纯 Python，约 1.2 MB，`t2s` 转换结果正常。

## 决定
1. **来源**：Tatoeba 官方按语言拆的三个导出文件，下载到 `data/tatoeba/`（不进仓库）。导出没有固定版本，所以不校验固定 sha256，而是在导入时打印每个文件的 `Last-Modified` 和 sha256；`--dir` 可以导入本地文件，结果可复现。和 ECDICT 一样在宿主机用 uv 运行。
2. **选句规则**（纯函数，有单测）：
   - 候选：有中文翻译、4–20 个词的英文句；英文句里出现这个词或它的变形（单词按整词匹配，短语按连续的词匹配，同 `word_forms`）。
   - 排序：先比“生词数”（除目标词外，不在词频前 5000 的词的个数，越少越好），再比和 9 个词的差距，最后按句子 id，结果稳定。同一个词的两句不能“只差一个词”（Tatoeba 常有 “an example to / for your children” 这类近似句），近似的只留排名靠前的一句。
   - 句子中间大写开头的词当作人名（Tom、China），不参与匹配，也不算生词；但词库里本来就大写的词（English、US）按原样匹配，所以 `us` 不会配给 `US`。
   - 带变形的词条不匹配它的原形（`held` 不配 “hold” 的句子），原形词条匹配所有变形。
   - 每个词最多存 **2 句**，和卡片显示的数量一致。
   - 一句英文有多条中文翻译时，优先用本来就是简体的那条；都是繁体就用 OpenCC `t2s` 转。
3. **存储**：`word_sentences`（`word_id`、`rank`、`en`、`zh`、`source`、`source_id`），主键 `(word_id, source, rank)`。和 `words` 一样是全局只读数据，不按租户隔离。重新导入时在一个事务里删掉 `source='tatoeba'` 的全部行再写入（没有别的表引用它）。
4. **署名**：卡片上写“来源：Tatoeba”，链接到这句的页面 `https://tatoeba.org/sentences/show/{source_id}`；README 的数据来源一节写明 Tatoeba、链接和 CC BY 2.0 FR。
5. **AI 例句**：复习卡片背面例句区下面放“AI 例句”按钮（`AiBadge word_examples`），点了才调用，复用现有接口和缓存（租户 + 词 + 等级）。没有真例句的词只显示按钮。不自动生成：每天新词都没缓存，翻面就调用会持续花 token。
6. **显示**：例句放在中文释义下面，默认展开（不放进“更多”）；英文句里目标词及变形加粗，下面是灰色中文。接口给复习队列、评分结果、生词本里的单词带 `sentences`（按 `rank` 排序）。

- **落地**（任务 28.2）：2026-09-26 导出实际导入 18,221 句，用时约 8 秒，内存峰值约 200 MB；有例句的词：牛津 3000 95%、中考 99%、高考 93%、CET4 89%、CET6 76%、考研 82%、雅思 72%、托福 52%、GRE 31%。

## 取舍
- 覆盖率随难度下降：GRE 只有约三分之一的词有真例句，这些词要靠 AI 按钮。是否在后台为第二天的词预生成 AI 例句，等看过实际使用再定（看板 P2 已记录）。
- 按词形匹配不区分词义：`saw`（锯 / see 的过去式）这类词可能配到另一个意思的句子。ECDICT 的释义通常两个意思都列了，影响有限；以后可以用 AI 例句或人工标注补。
- Tatoeba 的句子质量参差，有些偏口语或带人名（Tom、Mary）。按“生词少、长度适中”排序能挑出大多数好句子，不做人工审核。
- 每周的新导出不会自动拉取；需要时重新执行 `make sentences-import`。
