# 0051 · 私教看得到最近一张测验卡里的题

- **状态**：已采纳（2026-10-17，任务 95；按推荐确认：学习者明确要答案时可以直接说；真模型冒烟后用户确认：两种测验都给题面，接受讲题时可能顺带泄答案）
- **日期**：2026-10-17
- **影响**：修改 ADR 0044 §5 的“结果交回助手”：卡片上下文从“得分 + 答错的题”扩大到“最近一张测验卡的全部题目”。`cards/quiz.py` 新增 `QuizItem`，`QuizState.items` 取代 `wrong`（`wrong` 改为由 `items` 算出的属性）；`QuizState.describe` 和 `cards/service.py` 的 `describe` 新增 `questions` 参数；`render_context` 只给最近一张没撤回的测验卡展开题目；`tutor_tools.md`、`tutor_no_tools.md` 加规则。无迁移。

## 背景
- 学习者看着对话里的测验卡问“解释下这几个题目的出题意义”，私教回答“我目前看不到卡片里的具体题目”。
- 按 ADR 0044 §5，私教每轮拿到的测验卡上下文只有进度（“已答 N / 共 M 道”），做完以后才多给答错的题。卡片明明在对话里，私教却说不出卡里有什么题，学习者会觉得两边是分开的。

## 决定

### 1. 最近一张测验卡列出全部题目
- 每道题一行：题干、卡片上看到的内容（单选的四个选项、填空的提示、找错题带编号的片段）、作答情况和正确答案。
  - 没答的：写“not answered yet; key (say it only if they ask)”。
  - 答过的：学习者第一次的答案、对错、正确答案。答案和以前一样截到 160 字。
- 只展开最近一张没撤回的测验卡。更早的测验仍是一行摘要（做完的带答错的题），最近 10 张卡里有好几组测验时不会把提示词撑大。
- 展开的测验做完时不再重复写“missed”，题目行里已经有了。

### 2. 答案：明确要才给，泄露靠提示词约束
- 正确答案也放进上下文：学习者说“直接告诉我答案”时，私教要答得准。
- 提示词规定：问到题目时讲每题考什么、怎么想；没答的题不点名答案、不排除其他所有选项、不用例句填同一个空或翻同一句，学习者明确要答案时才给。测验还没答完时，这条规则也贴在题目列表前面。
- 真模型冒烟（百炼 qwen-plus）：
  - 给题面时，私教能逐题讲，要答案时给得准；但解释“出题意义”时每轮都顺带说出了答案，两次收紧措辞都没用。题目简单，不给 key 模型也能自己做出来。
  - 过关测验没答的题只给题型时，不泄答案了，但私教会**自己编题**（“如：她每天刷牙三次”），还给编出来的题报答案，写明“别猜别编”也没用。
  - 编题会误导学习者，泄答案只是让测验变容易、而且是学习者自己问的，所以两种测验都给题面。

### 3. 不进 checkpoint
- 和以前一样，卡片上下文每轮重新读取，走 `UntrackedValue` 通道，只作为数据进 system prompt。

## 没有选的方案
- **过关测验没答的题只给题型**：冒烟中模型编题、给编的题报答案，比泄答案更糟。
- **没答的题都不给答案**：挡不住泄题，模型看到题面自己就能做出来；学习者明确要答案时反而给不准。
- **所有测验都展开**：最近 10 张卡里可能有好几组测验，每组 5 题，每轮都带上太费 token，而学习者问的几乎总是眼前那一组。
- **放进长期记忆**：记忆异步写入、按相关度检索，题目会晚到或被漏掉；测验题只在当前对话有意义，写进长期记忆反而是噪音。

## 后果
- 有测验卡的对话，每轮的 system prompt 多出最近一组题，约几百 token。
- 守规则弱的模型讲题时会顺带说出没答的题的答案，过关测验因此可能变容易、掌握度偏高。要严格保护计分，可以在回复后用代码检查回复里有没有没答的过关题的答案，命中的题不计分、不记证据（待用户确认，任务 95.3）。
