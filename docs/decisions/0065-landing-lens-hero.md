# 0065 · 首页改成放大镜单词墙 + 聊天窗口演示

- **状态**：已采纳（2026-10-26，任务 125.1；版式按用户认可的 mockup，Q125a、Q125b 用户 2026-10-26 按推荐确认）
- **日期**：2026-10-26
- **影响**：**取代 ADR 0037**（WebGPU shader 背景整套去掉，`shaders` 依赖删除）；ADR 0038 提到的首页叠卡插图随之去掉（背单词弹层本身不受影响）。`components/home/` 重写；`globals.css` 删掉 `.landing-silk` / `.landing-ink`；新增自托管字体 Archivo（只在首页加载，ADR 0059、0060 的自托管原则不变）。只影响未登录首页。

## 背景
- ADR 0037 的流光背景好看，但信息是靠下面的卡片讲的，首屏本身只说明“这是个产品”，没说明“它怎么教英语”。shader 的 chunk gzip 后约 730KB，还持续占用 GPU；无头浏览器看不到，只能人工确认。
- 用户在 `notes/mockups/lens-hero.html` 上迭代出新版首页并认可（2026-10-26）：首屏直接演示“私教看你的英语”，第二屏演示真实的对话过程。

## 决定
1. **第一屏：单词墙 + 放大镜**
   - 整屏铺一面斜放的巨型英文单词墙（学习相关词，固定种子打乱，每次加载一样），中间夹几个常见错词（Informations、Recieve……）。
   - 一个玻璃球放大镜跟随鼠标：镜下单词变成品牌色并放大，旁边浮出词条（音标、释义、CEFR 等级；错词显示红色和改法）。中文界面显示中文释义，英文界面显示英文释义。
   - 放大用 DOM 复制一份墙 + SVG `feDisplacementMap` 做桶形畸变，不用 canvas / WebGL。墙用独立合成层（`will-change: transform`），平移不重绘。
   - 交互：鼠标视差、滚轮拖动墙；鼠标离开 hero 或闲置时镜片自己慢慢漫游；触屏没有悬停和滚轮，墙和镜片自己漫游，手指按下时镜片跟手、抬起后停在原处。
   - 标题、副标题、CTA、顶栏（品牌、语言按钮、登录、注册）由服务端渲染，首屏文字不等 JS；单词墙和放大镜是装饰，`aria-hidden`。
2. **第二屏：聊天窗口演示**
   - 一个仿真聊天窗口，5 个场景自动轮播，顶部的标签可以点：记忆 + 纠错、练习卡 + critic、精读工作区、写作工作区、分段回复（ADR 0064）。工作区在桌面上并排滑出，≤820px 时盖住聊天窗口、带返回箭头。演示的步骤名和“JOJO 做了什么”与产品里的一致。未登录时拿不到租户设置的私教名字，固定写 JOJO（和旧首页一样）。
   - **懒加载**：服务端只输出标题、标签和一个空窗口；播放器（场景脚本和 DOM 构建）是单独的模块，IntersectionObserver 在窗口离视口一屏以内时才动态 `import()` 它，所以它不在首屏的 JS 里、不挡首屏渲染。第二屏紧贴在 100svh 的 hero 下面，实际上水合后很快就会加载；要省的是首屏的解析和执行，不是这一次请求。
   - **暂停**：只在窗口可见（threshold 0.35）且标签页可见时推进；动画时钟用 rAF，每一步等待都绑一个 run token，切场景、切语言、卸载时作废，正在等的步骤直接退出。
   - 屏幕阅读器读 `aria-live` 里的场景文字，不读动画过程。
3. **第三屏起**：会记会教的功能卡片、深色的“看得见、管得住”说明带、开源自部署、结尾 CTA 和页脚，都是静态服务端组件，进入视口时淡入（纯 CSS + 一个 observer）。
4. **减少动态效果**：墙不动、镜片停在固定位置、不漫游；演示直接显示每个场景的最后一帧、不自动轮播（标签仍可点）；卡片不淡入。
5. **语言切换**（Q125b）：照 mockup 用一个“English / 中文”按钮，写入现有的语言 cookie（和 `LocaleSwitcher` 同一机制），切换后页面重新渲染；所有文案在 `messages/*.json` 的 `landing` 下，不在组件里放字典。
6. **字体**：单词墙和大数字用 Archivo（OFL，可变字体 wdth 62–125、wght 100–900，拉丁子集 woff2 约 88KB），放在 `src/fonts/`，用 `next/font/local` 引入，只在首页的模块里 import，所以只有首页预加载它。正文仍用全站字体。
7. **去掉的东西**（Q125a）：WebGPU 背景（`landing-backdrop` / `landing-shaders`）、插图（`landing-stills`）、旧的聊天演示、纠错跑马灯、首页上的小猫，以及 `shaders` 依赖。mockup 里的调参用变量不进产品，写成常量。

## 取舍
- **体积**：去掉 shader 后，首页少一个约 730KB（gzip）的懒加载 chunk。新增的是 Archivo 88KB 和演示组件（懒加载）。以后嫌字体大，可以用 fonttools 固定成单一字重 / 宽度再子集化到大写字母。
- **性能**：墙是几百个大字号的 DOM 节点，复制一份放进镜片后节点数翻倍。靠合成层平移和只在镜片里应用滤镜控制开销；低端设备上如果掉帧，先考虑减少墙的行数。
- **兼容**：SVG 滤镜所有现代浏览器都支持，不再像 WebGPU 那样有一部分用户只能看到静态底色；E2E 和截图看到的就是真实效果。
- **演示和产品会漂移**：演示是手写脚本，不调接口。产品里的步骤名或工作区布局改了，要同步改演示的文案；文案都在 `messages` 里，搜 key 就能找到。
