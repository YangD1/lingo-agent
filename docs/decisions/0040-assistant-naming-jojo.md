# 0040 · 改称“助手”，默认名 JOJO，名字是编辑入口

- **状态**：已采纳（2026-10-15，任务 79；Q79a–d 全部按推荐确认）
- **日期**：2026-10-15
- **影响**：**补充 ADR 0032 §1**（默认名由 Lingo 改为 JOJO）、**ADR 0013**（回复下的公示行从“私教做了什么”改为“{名字}做了什么”）。不新增模型调用，不需要迁移。

## 背景
- 桌宠小猫（ADR 0032 §4a）已经是学习者每天看到的“角色”，名字也能改，但界面各处仍叫它“私教”，默认名 Lingo 和产品名 Lingo Agent 撞在一起，很难当成一个有名字的角色。
- 回复下面的“私教做了什么”（ADR 0013）是学习者看得最多的地方，却没有通往名字和形象的入口：想改名要先知道侧栏里有“我的私教”。

## 决定

### 1. 称呼（Q79a、Q79b）
- 界面里指代这个角色时统一叫“**助手**”（英文 **assistant**），有名字的地方用名字。例如侧栏“我的助手”（Q79d，固定文字，不随名字变，长名字不会撑乱侧栏），编辑页标题“{名字}：名字、形象和声音”。
- 替换范围：界面文字（中英文）和公开文档（`README.zh-CN.md`、`docs/agent-tools.md`、`docs/demo.md`）。ADR、PLAN 正文和历史计划里的“私教”保留不改，免得历史记录和当时的提交对不上；以后新写的文档用“助手”。
- 系统提示词里的角色（英语老师）不变，只是界面叫法变了。

### 2. 默认名 JOJO
- `tutor_profiles.name` 为空时用 JOJO（原来是 Lingo）：提示词里“你叫 JOJO”，界面显示 JOJO。
- 已经存过名字的人不动，包括手动存成 “Lingo” 的：那是学习者自己的选择，不做数据迁移。

### 3. 名字是编辑入口（Q79c）
- 回复下的公示行改成“**{名字}**做了什么：…”。名字单独做成品牌色、虚线下划线的链接，去 `/tutor#looks`；后面的“做了什么：…”仍是展开明细的按钮。两者是相邻的两个元素，不把链接嵌进按钮。
- 到达 `/tutor#looks`：形象卡片按锚点高亮闪一下（复用设置页的 `hash-flash`），光标落在名字输入框。
- 首页（未登录）对话示例里写死“JOJO做了什么”，不可点。

## 不做
- 不给角色加性格 / 说话风格（ADR 0032 §1 的理由不变）。
- 不改产品名 Lingo Agent 和品牌 logo 小猫 `LingoCat`。
