# 0017 · 对话的中英比例、单词气泡与浏览器朗读

- **状态**：已采纳（2026-10-01；Q24a–Q24j 由用户确认）
- **日期**：2026-10-01
- **影响**：修订 `tutor_system.md`（回复语言改为按学习者设置渲染）；`user_profiles` 新增 `chat_language`；新增查词、AI 例句、气泡翻译三个接口和两个模型任务（`word_examples`、`translate`）；朗读先用浏览器 `speechSynthesis`，PLAN 里“TTS 在 P3 走 provider”的安排不变，只是提前给出一个不调用任何模型的版本。原来聊天里“选中单词加生词本”（ADR 0011）并入单词气泡。

## 背景
用户建议（2026-10-01）：
- 私教一直说英文，英语弱的学习者读得吃力，心理负担一下就上来了。应该能选“多说中文”还是“多说英文”，之后也能切回来；最好还能按条切换中文版和英文版。
- 私教气泡里的英文单词，鼠标悬停时要弹出单词气泡，能朗读、看例句；私教气泡本身也要能朗读。

现状：
- `prompts/tutor_system.md` 写死“Reply in natural, clear English”。画像里的 `explanation_language` 只在练习对话里用来决定讲语法用什么语言。
- 词库（ECDICT）有音标、中文释义、英文释义、词形变化，没有例句。`services/vocab/mine.py` 的 `lookup()` 能按原形找词（went → go），但没有查词接口。
- 后端没有 TTS；前端只有背单词页用了 `speechSynthesis`。

用户已确认：
- Q24a：全局“多说中文 / 多说英文”开关，加上每条私教气泡可以切换看中文版 / 英文版。
- Q24b：分两档。没手动选过时按等级给默认：A1–A2 多说中文，其他多说英文。
- Q24c：例句 = 这个词在气泡里的原句（免费），加上按需的“AI 例句”（按词缓存）。
- Q24d：朗读先用浏览器 `speechSynthesis`。服务端 TTS 另开任务 25。
- Q24e：没有等级（没做入学测）时默认多说中文。
- Q24f：“多说中文”= 聊天、讲解、提问、鼓励用中文；目标表达、例句、纠正后的句子用英文；鼓励用英文回答，但学习者用中文回也照常接着聊。
- Q24g：开关是全局的（存在画像里），不分对话；切换后下一句生效。
- Q24h：气泡翻译翻成“另一种语言”：以英文为主的气泡给中文版，以中文为主的给全英文版。译文存库，来回切换不再调模型。
- Q24i：单词气泡只出现在私教气泡里（代码块除外）。桌面端悬停 0.3 秒弹出，触屏点按弹出。原来的“选中单词加生词本”并入单词气泡。
- Q24j：AI 例句按“租户 + 词 + 等级”缓存，同一租户的学习者共用。

## 决定

### 1. 中英比例
- `user_profiles.chat_language`：`zh` / `en` / null。null 表示没手动选过。
- 生效值：手动值优先；否则按 `cefr_level`：A1、A2 或没有等级时为 `zh`，其他为 `en`。由 `app/memory/language.py` 的纯函数 `chat_language()` 计算，接口和提示词共用。
- `GET /profile` 同时返回存的值和生效值（`chat_language_effective`）。`PATCH /profile {chat_language}` 修改，计入 `manual_fields`；传 null 恢复按等级自动。反思不会写这个字段。
- 提示词：`tutor_system.md` 里的语言规则换成按生效值渲染的一段（`prompts/language_zh.md` / `language_en.md`）。system prompt 每轮重新拼，所以练习、规划、今天的对话和普通对话都按当前值，切换后下一句生效，已经说过的话不变。
- `zh` 时讲语法也用中文；`en` 时讲语法仍按 `explanation_language`（不变）。

### 2. 查词与单词气泡
- `GET /vocab/lookup?word=`：复用 `mine.lookup()`。返回词条（音标、中文释义、英文释义）、匹配方式（原词 / 大小写 / 原形）、是否已在生词本。不调模型。词库里没有时返回 404 `word_not_found`（沿用加生词本的错误码）。
- 前端：私教气泡的 Markdown 渲染时，把正文里的英文单词包成可交互的 span（代码块、行内代码、链接除外）。桌面端悬停 0.3 秒、触屏点按，弹出单词气泡，内容依次是：
  - 单词、音标、朗读按钮；
  - 中文释义（最多 3 行），如果是按原形匹配到的，注明“原形 go”；
  - 原句：这个词所在的那一句（从气泡文本里切出来）；
  - “AI 例句”按钮（带 `AiBadge`）；
  - 加入生词本（`POST /vocab/mine`，已经在生词本里就显示“已在生词本”）。
- 原来的 `SelectToAdd`（选中单词出现“加入生词本”）删除，功能并入单词气泡。

### 3. AI 例句
- `POST /vocab/words/{id}/examples`：新模型任务 `word_examples`，结构化输出 2 句，每句是英文 + 中文翻译，难度按学习者的等级。
- 代码校验：每句英文都要包含这个词或它的变形（按 `exchange` 展开）。不合格的丢掉；一句都没通过时返回 502 `examples_invalid`，不缓存。
- 缓存表 `word_examples`（tenant_id、word_id、cefr、句子 JSON、created_at），主键是前三个字段。命中缓存直接返回，不调模型，也不记用量。
- 例句不是练习或题目，不走 critic 节点（CLAUDE.md 的 critic 约束针对练习和题目）；只做上面的代码校验。

### 4. 气泡翻译
- `POST /conversations/{id}/messages/{message_id}/translate {target: "zh" | "en"}`：新模型任务 `translate`，结构化输出（`{text}`）。只翻私教消息，保留 Markdown 格式。
- 前端决定目标语言：气泡里英文字母多于汉字就翻成中文，否则翻成英文。
- 缓存表 `message_translations`（conversation_id、message_id、target、text、created_at）。会话删除时一起删除。命中缓存直接返回。
- 前端：每条私教气泡下有“看中文 / 看英文”和“看原文”切换。译文在原位置替换显示，单词气泡和朗读对译文同样可用。

### 5. 浏览器朗读
- `lib/speech.ts`：把背单词页的 `speak()` 挪过来共用。私教气泡的“朗读”按钮先把文本按文字种类切成中文段和英文段，分别用 `zh-CN`、`en-US` 声音依次读；再点一次停止。浏览器不支持 `speechSynthesis` 时不显示按钮。
- 朗读的是气泡渲染后的纯文本（去掉 Markdown 符号和代码块）。
- 不调用模型，也不经过后端，所以不登记 `features.yaml`，不挂 AI 标记。
- 服务端 TTS 是任务 25。
- **已被 ADR 0018 修订（2026-10-01）**：浏览器朗读改为自己挑声音（按语言和质量打分、中英尽量同性别）、按句切分、学习者可以在当前浏览器里选声音、口音和语速；服务端朗读改为租户可选的连接（兼容 OpenAI 的 `/audio/speech` 或 Azure 语音），不内置 edge-tts。

## 公示（ADR 0013、0014）
- `features.yaml` 新增 `word_examples`（task `word_examples`，立即）和 `message_translate`（task `translate`，立即）。前端在“AI 例句”和“看中文 / 看英文”旁挂 `AiBadge`。
- `docs/agent-tools.md`：AI 用量标记表加这两项；另加“对话之外的调用”一小节，说明它们不属于对话轮次，所以不写 `agent_activities`（与入学测相同），缓存命中时不调模型。
- 中英比例是学习者自己的设置，在记忆页的画像里可以查看和修改。

## 取舍
- **全局开关而不是按对话**：学习者的英语水平不会因为对话不同而变，一个开关更好理解。代价是想在某段对话里临时换语言，得来回切。
- **按等级给默认**：新学习者和低等级的人一开始就看中文，压力小；等级上去以后自动转为英文为主，除非手动选过。没有等级时选中文，是因为英语弱的人更需要照顾，而开关就在输入框上方，随时能切。
- **翻译存库**：多一张表，但同一条消息来回切换不会重复花钱，翻译结果也稳定。
- **例句按租户共享缓存**：例句只和词、等级有关，不含个人信息。同租户共享可以省钱；不跨租户共享，因为每个租户用自己的模型和 key 付费。
- **浏览器朗读**：免费、不占服务器内存（线上服务器配置很低，见 ADR 0001），马上能用；缺点是不同设备的音色不一样。服务端朗读放在任务 25 解决。
- **单词气泡包住每个英文单词**：渲染时多一些 span，但长回复也就几百个，不影响性能。悬停有 0.3 秒延迟，鼠标划过时不会到处弹。
