# 0027 · 每日计划：算法出草案，私教只负责改

- **状态**：已采纳（2026-10-09，任务 48；Q48a–h 按推荐确认）
- **日期**：2026-10-09
- **影响**：新增 `backend/app/adaptive/daily_plan/`、`daily_plans` 表、`rules.yaml` 的 `daily_plan` 节、私教工具 `propose_daily_plan`、确认卡类型 `daily_plan`；确认卡的确认接口可带调整后的参数（只对 `daily_plan`）；看板加“今天的计划”区块。不加定时任务。

## 背景
P2 计划 §7：每天第一次打开看板，私教给出今天的计划（复习 N 个词、学 M 个新词、一组练习、一篇阅读、可选写作），学习者在确认卡上确认或调整，看板上能看到完成情况。ADR 0025 把“每日计划预计算”列为定时任务。

核实（2026-10-09）：

- “今天”对话（ADR 0016，purpose `daily`）没有开场，私教只在学习者发消息后回复；让私教每天自动开场提计划，就是每个学习者每天多一次模型调用，没配置模型的学习者也就没有计划。
- 计划里每个数都已经能由算法得出：到期复习数和今天还能学的新词数（`vocab/queue.today_counts`）、选题最高的语法点（练习选题）、可读的文章（阅读来源与改写缓存）、最近一次写作时间。
- 完成情况在各模块都已有时间戳：`review_logs.reviewed_at`、`user_cards.first_reviewed_at`、`exercise_sets.finished_at`、`reading_sessions.finished_at`、`writing_submissions.created_at`。
- 确认卡（ADR 0015）的确认接口不带参数，卡片上不能改数量。

## 决定
1. **算法出草案（Q48a）**：当天第一次读计划（打开看板）时，纯函数按规则生成计划，不调用模型，存成一行 `daily_plans`（学习者本地日期唯一），看板上的计划区块就是它的确认界面；不为草案造一张确认卡，也就不用为没发生的对话轮次编 `turn_id`。学习者想改时在“今天”对话里说，私教用 `propose_daily_plan` 重提一份，参数经代码校验、预计时间由代码算，是一张 `daily_plan` 确认卡（ADR 0015）；确认后替换当天 `daily_plans` 里的计划，撤销这张卡就换回之前的计划。
2. **分配（Q48b）**：按 `user_profiles.daily_minutes`（没填用 `daily_plan.default_minutes`）分配，顺序 复习 → 一组练习 → 新词 → 阅读 → 写作：复习先最多占 `review_share` 的时间；练习、阅读、写作放得下才放；新词不超过词书每日余量；阅读只在有可读文章时放；写作只在总时间 ≥ `writing_min_minutes` 且 `writing_gap_days` 天内没写过时放；最后剩下的时间再补给积压的复习。估时都在 `rules.yaml`。
3. **调整（Q48c）**：卡片上复习、新词可增减，练习、阅读、写作可开关，显示预计总时长；确认时带上调整后的参数，代码重新校验范围、重算时间。
4. **完成情况现算（Q48d）**：不存完成事件，读计划时按学习者本地当天从各模块记录算：复习次数、开始学的新词数、完成的练习组 / 读完的文章 / 提交的写作。不要求是从计划点进去的。不提供手动勾选。
5. **数量固定（Q48e）**：当天第一次生成后数量不再随状态变，想换就让私教重提；过了当天没确认的计划不再显示。
6. **拒绝与撤销（Q48f）**：“今天不要计划”后看板只留一行说明；确认后可撤销，撤销回到待确认。
7. **不加定时任务（Q48g）**：计划是纯算法、读的时候现算只要几毫秒，ADR 0025 第 4 条的“每日计划预计算”取消。
8. **位置（Q48h）**：看板统计卡下面、“今天”私教上面；对话里私教提的计划卡也显示在对话里，确认后看板随之更新。

## 取舍
- 不让私教每天开场：省掉每天一次模型调用，没配模型也有计划；代价是计划本身没有私教口吻的理由。理由可以在学习者问时由私教在对话里讲（brief 里有计划和各项依据）。
- 完成情况现算而不是存事件：不用在各模块埋点，删除学习记录后自然一致；代价是“从计划点进去”这件事不区分，对学习者来说做了就算做了，正合适。
- 数量固定：学习者确认前后看到的数一致，不会出现“刚才 30 个，刷新后变 34 个”；代价是确认前状态变了也不跟着变，想要新的就让私教重提。

## 补记：口语一项（任务 59.6，2026-10-10，ADR 0029 §6）
