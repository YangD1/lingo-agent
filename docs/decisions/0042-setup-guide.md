# 0042 · 配置引导：新账号第一次进应用先走引导，可跳过、可重复进入

- **状态**：已采纳（2026-10-15，任务 82；Q82a–e 全部按推荐确认）
- **日期**：2026-10-15
- **影响**：新增全屏页 `/setup`；`users` 加 `setup_completed_at`（一次迁移，老账号回填）；新增 `GET /me/setup`、`POST /me/setup/complete`；`(app)` 布局在没走完引导时跳转 `/setup`。桌宠“没配模型”的提醒和快捷动作改为指向引导的模型一步。不新增模型调用和 agent 工具。

## 背景
- 注册后直接进看板，什么都没配。要配的东西分散在三处：设置页（连接、8 个路由节和其他 9 节）、记忆页“关于我”、“我的助手”页；入学测又在 `/placement`。新用户不知道先配什么、哪些必须配，心智负担大。
- 其实“能用起来”只需要很少几项：只要有一个连接，路由匹配不上会用默认模型兜底（ADR 0007）；加入别人的组织后可以用主账号的模型（ADR 0031）。其余是锦上添花。

## 决定

### 1. 形式与触发（Q82a、Q82c、Q82d）
- 独立全屏页 `/setup`，不带侧栏和桌宠，手机上也是一屏一步。
- `users.setup_completed_at` 为空时，`(app)` 布局（服务端）把除 `/setup`、`/join` 外的页面都跳到 `/setup`。
- **只有走到最后一步点“完成”，或在第一步点“全部跳过”，才算走完**（写入 `setup_completed_at`）；中途关掉页面，下次进应用仍回到引导。走完是账号级的，换设备不再弹。
- 迁移时老账号全部回填为已走完，不打扰；想看可以从入口重新进入。

### 2. 步骤（Q82b、Q82e）
五步，每步都有“跳过”，顺序如下：
1. **称呼和语言**：怎么称呼你（`users.display_name`）、讲解语言（`user_profiles.explanation_language`），时区由浏览器自动带出。
2. **接入模型**：选厂商预设、粘贴 key、点测试（沿用 `/tenant/connections` 的创建和测试接口），测通后自动发现并设默认模型；或者“我有邀请码”，走加入组织。已经有可用模型（自己的或主账号的）就直接显示“已就绪”。**跳过要二次确认**：“没有模型，对话、练习、阅读改写都用不了”，之后桌宠和看板照旧提醒。
3. **学习目标**：目标、目标考试、每天分钟数、兴趣（`user_profiles`，提交的字段记进 `manual_fields`，反思不覆盖）。
4. **助手**：名字（默认 JOJO）和形象（`tutor_profiles`）。
5. **水平测试**：现在去做入学测，或以后再说；没模型时说明要先接模型。

最后是完成页：列出配好的和跳过的项，跳过的项给出以后去哪改的直达链接；转写、朗读、实时语音等进阶项不进引导，完成页指去设置页对应锚点。

### 3. 各步状态由真实数据算
- `GET /me/setup` 返回走完时间和每步现状：有没有可用的对话模型、称呼和讲解语言、学习目标各字段、助手名字和形象、入学测做没做过。引导据此打勾和预填，不另存“哪步跳过了”。
- 引导只调用已有的业务接口写数据（`PATCH /profile`、`PUT /tutor`、连接接口等），自己只新增“读现状”和“标记走完”两个接口，外加 `PATCH /auth/me` 改称呼（原来只能注册时填）。

### 4. 重复进入
- 设置页顶部和用户菜单都有“配置引导”入口。再次进入时各步按现状预填、已配的打勾，没改的字段不重复提交；再点“完成”只是更新时间。
- 桌宠“没配模型”的提醒和“配置模型”快捷动作改为指向 `/setup?step=model`（原来是设置页连接卡片）。

## 公示（ADR 0013、0014）
- 引导本身不调用模型（连接“测试”是已有接口），不新增 agent 工具、MCP 或后台步骤，`features.yaml` 和 `docs/agent-tools.md` 不变。入学测入口沿用已有的 `AiBadge`。

## 取舍
- **全屏页而不是弹窗**：五步内容在手机上叠弹窗会挤；独立页面也方便从设置页、桌宠直接链过去。
- **“完成”才算走完**：比“跳过一步就算”更不容易因误点而再也不弹；代价是中途离开会被带回来，但第一步就有“全部跳过”。
- **模型可跳过但要确认**：允许先看看界面再决定接哪家，又不会让人不知情地进入一个处处报错的应用。
- **状态不另存**：每步是否完成直接看真实配置，引导和设置页永远一致，不会出现“引导说没配、其实配了”。
