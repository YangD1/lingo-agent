# 0038 · 背单词从独立页面改为遮罩弹层叠卡

- **状态**：已采纳（2026-10-14，任务 75；Q75a–e 全部按推荐确认）
- **日期**：2026-10-14
- **影响**：前端新增 `components/vocab/review-deck*.tsx`（弹层、叠卡、动效），`(app)/layout.tsx` 挂载弹层宿主；`ReviewApp` 拆掉页面外壳，界面逻辑搬进卡片；`/vocab/review` 改为跳转；看板、背单词首页、建议卡片、私教链接卡片、每日计划的入口改为打开弹层。后端不变。

## 背景
- 现在的 `/vocab/review` 是全屏独立页（`isFocusRoute` 隐藏侧栏和手机底栏），进出都要整页跳转，背完回不到原来的页面。
- 首页（ADR 0037）“FSRS 背单词”那张叠卡（`VocabStill`：正中一张卡，后面两张斜放）用户觉得好看，希望点开就在当前页面弹出这样的卡片直接开始背。
- 会话逻辑已经独立在 `use-review-session.ts`（取卡、评分、题型、撤销），界面可以换壳而不动逻辑。

## 决定
- **功能全部保留（Q75a）**：三种题型（认词、听音选义、拼写）、键盘快捷键、建议评分和各评分的下次间隔、朗读、“读不准”标记、加入生词本、AI 例句、跟读、结束页和桌宠庆祝，都挪进卡片。卡片高度固定在视口内，背面内容多时卡片内部滚动，评分按钮固定在卡片底部。
- **用 URL 参数驱动弹层（Q75d）**：弹层宿主 `ReviewDeckHost` 挂在 `(app)/layout.tsx`，监听当前页面的 `?review=all|new`。
  - 任何页面都能打开：入口链接写成只带查询参数的 `?review=all`，留在当前路径上。
  - 打开时 `push`，所以手机返回键、浏览器后退能关掉弹层；Esc 和关闭按钮也是退回上一条历史。直接带参数进入（没有可退的历史）时改用 `replace` 去掉参数。
  - 关闭后留在原页面，原页面的状态不丢（弹层不卸载页面）。
- **`/vocab/review` 保留（Q75b）**：改为服务端跳转到 `/vocab?review=all`（`mode=new` 对应 `review=new`）。书签、私教提示词里的路径（`tutor_no_tools.md`）、历史消息里的链接都还能用，后端不用改。`isFocusRoute` 随之删除。
- **叠卡样式与动效**：
  - 模糊遮罩（`backdrop-blur` 加半透明墨色），卡片居中，后面两张斜放的卡沿用 `VocabStill` 的角度和层次，后面的卡数量随剩余卡片减少。
  - 翻面用 3D 翻转（`rotateY`，`backface-visibility: hidden`）；评分后当前卡朝评分方向飞出（Again 向左，其余向右），下一张从牌堆升上来补位；一轮背完牌堆收拢，再翻出结束页。
  - 动效只用 CSS transform / opacity 和 `transitionend`，不引入动画库（低配服务器不受影响，但前端包也要克制）。
  - 系统开了“减少动态效果”时，所有位移和翻转换成淡入淡出。
- **手机手势（Q75c）**：卡片翻到背面后，左滑 = Again，右滑 = Good；拖动时卡片跟手并显示将要打出的评分，没过阈值松手回弹。Hard / Easy 点按钮。正面不响应滑动，避免误评。
- **顶部细栏（Q75e）**：卡片上方一条细栏：进度 x/y、题型切换、关闭按钮。
- **无障碍**：弹层是 `role="dialog"` + `aria-modal`，打开后焦点锁在弹层内，关闭后焦点回到触发的入口；背景页面 `inert`。键盘快捷键只在弹层打开时生效。

## 取舍
- **URL 参数 vs 全局状态**：用全局状态（context）打开更简单，但私教发的链接、计划里的链接都是字符串 href，要么每处改成按钮，要么拦截链接点击。URL 参数让所有入口仍然是普通链接（可以新标签打开、可以分享），返回键关闭也是顺带得到的。代价是打开和关闭会触发一次客户端路由（只改查询参数，页面不重新取数据）。
- **独立页面没了**：想全屏专心背的用户，弹层本身就盖住整个视口，体验接近；手机上卡片占满宽度。
- **测试**：动效在 E2E 里通过 `reducedMotion: "reduce"` 关掉，避免等动画；手势用单测模拟 pointer 事件。
