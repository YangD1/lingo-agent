# 0061 · 背单词卡片上标“熟记”，以及加回复习

- **状态**：已采纳（2026-10-21，任务 120；用户定：加回入口是新页“已熟记的词”，加回后接着原来的进度，点了不确认、弹提示可撤销）
- **日期**：2026-10-21
- **影响**：**补充 ADR 0011 §5**（`known` 卡除了熟词筛选和定级测试，也可以在卡片上标；新增“加回”）。后端新增 `services/vocab/known.py` 和三个接口；前端卡片加按钮、新增 `/vocab/known` 页。没有模型调用、没有 agent 工具，`features.yaml` 和 `docs/agent-tools.md` 不变。

## 背景
熟词筛选只覆盖还没见过的词书词，而且一批一批过；复习中遇到已经会了的词（包括已经在学的），只能每次都评“很熟”，间隔再长也还会回来。学习者想在卡片上直接说“这个会了，别再出”，也要能后悔。

## 决定

### 1. 接口
- `POST /vocab/cards/{word_id}/known`：卡片 `status=known`；没有卡片的词（还没见过的词书词）建一张 `source=book` 的 known 卡。FSRS 字段保留不动。幂等。词典里没有这个词时 404。
- `DELETE /vocab/cards/{word_id}/known`：加回。幂等：不是 known 或没有卡片时什么都不做，都回 204。
- `GET /vocab/known?q=&limit=&offset=`：所有 known 卡，不管是卡片上标的、熟词筛选勾的、定级测试标的还是生词本里的；按 `updated_at` 倒序（最近标的在前）；`q` 按开头搜索、不分大小写；每条带 `source`。

### 2. 加回后接着原来的进度
- 复习过的（`state` 不为空）：回到 `learning`，`due=now`，下次打开就出现在复习里，稳定性、难度沿用。
- 没复习过、来自生词本的（`auto` / `manual`）：回到 `new`，按生词本的顺序作为新词出现。
- 没复习过、来自词书或定级测试的：**删卡**。每日队列只把“没有卡片的词书词”当作新词（`queue.next_new`），设成 `new` 会永远排不上；删掉后它按词频回到词书的新词里。（方案确认时写的是设 `new`，实现时改成删卡，效果相同。）
- 卡片上的“撤销”就是同一个 `DELETE`：刚才那张放回最前面，重新开始一轮（不带上一次的答案）。

### 3. 卡片上的按钮和提示
- 按钮在卡片标签行右侧（“新词”“生词本”那一行），正反面都有；点了不确认，卡片像评过分一样飞走，不计评分、不写 `review_logs`、不算“今天已开始的新词”。
- 提示“已标为熟记，不再复习 · 要加回来：背单词 → 已熟记的词”，带“撤销”。提示挂在卡片弹层**里面**自己的 Toaster（`id="review-deck"`）上：弹层是 Base UI 模态框，弹层外的 toast 被点时算“点了外面”，会把卡片关掉。位置在顶部，底部会挡住“显示答案”和评分按钮。
- 关卡片时把这一轮的提示 dismiss 掉：sonner 的 toast 存在全局 store 里，下一个挂载的 Toaster 会把还没消失的再显示出来。
- 标了熟记也算这一轮有改动，关卡片时让下面的页面刷新计数。

### 3a. 和每日新词额度的关系（2026-10-21 补充，任务 123）
- 标熟记**不占**每日新词额度（额度只数 `first_reviewed_at` 在今天的卡）：熟记不花学习时间，空出的名额由词书里的下一个词顶上，每天真正学的新词数才对得上。
- 但补词不悄悄接上：一轮卡用完后前端会重新取队列（让刚答错的卡回来），这时队列里的复习卡照常接上，新词先扣住；结束页说明“你标了 N 个熟记，熟记的词不占今天的新词名额，还能再学 M 个新词”，按钮“再学 M 个” / “今天到此为止”。只有一开始那批新词直接出。
- 之前没有这一步，标完一批熟记就紧接着又来一批新词，看起来像额度失效。

### 4. “已熟记的词”页
`/vocab/known`，背单词首页“我的生词本”旁边有入口。搜索、分页，每个词显示来源（词书 / 生词本 / 定级测试）和上次复习时间（复习过才有），“加回复习”不确认，加回后从列表里去掉，并说明它会马上出现在复习里还是作为新词再学。

## 取舍
- 来源只有 `source` 一列：卡片上标的和熟词筛选勾的都是 `book`，页面上分不开。要分开得加一列，没必要。
- 定级测试的“撤销整批”（ADR 0015）只删仍是 known 的 `placement` 卡，所以加回过的词不受影响；在卡片上又标回熟记的 `placement` 卡会被整批撤销一起删掉，也就是变回没见过的词，可以接受。
- 加回复习过的词时不恢复标熟记之前的 `due`，统一 `due=now`：标熟记的入口只在复习卡片上，那时它本来就到期了；从“已熟记的词”加回的，学习者就是想再复习它。
