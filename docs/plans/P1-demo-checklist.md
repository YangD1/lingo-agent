# P1 Demo 实测清单

用真实模型在 Docker 全栈上走一遍 P1 的全部功能（任务 20）。自动化测试（pytest、Vitest、Playwright）只用假模型，这里要看的是：流程在真实环境里通不通，以及模型写出来的东西好不好。

- **环境**：`make up` 之后打开 <http://localhost:3000>。词库已导入（`make vocab-import`，约 3.8 万词）。
- **账号**：用一个**新邮箱**注册，从空状态开始，看引导是否合理。
- **时间**：约 30 分钟。第 3 步入学测最长，约 10 分钟。
- **怎么记**：每步有“应该看到”。和预期不一样的，按文末的格式记下来；觉得别扭、看不懂的地方也记，不必是 bug。

---

## 1. 注册与空状态

| 做什么 | 应该看到 |
|---|---|
| 注册新账号 | 直接进入**看板**。各区块都是引导（去做入学测、选词书、去对话），没有空图表 |
| 看“今天的建议” | 两条模板建议：做入学测、选一本词书；状态写“还没配置模型”，带去设置的链接 |
| 打开**对话** | 顶部有入学测引导条 |

## 2. 配置模型

| 做什么 | 应该看到 |
|---|---|
| **设置 → 模型连接**：添加你常用的连接，填 key，保存默认模型 | 模型列表能拉出来；“测试”通过 |
| （可选）添加语音转写连接（如硅基流动），在“语音转文字”里选上 | “测试”按转写来测并通过 |
| （可选）配置看图模型 | 同上 |

> “后台整理模型”（反思、记忆）和学习建议不设置时，都走默认路由。

## 3. 入学测

| 做什么 | 应该看到 |
|---|---|
| 点引导条或导航的**入学测** → 开始 | 第一部分词汇：每题判断认不认识，里面混着假词 |
| 中途关掉页面，再回来 | 从刚才那题继续 |
| 做完第二部分语法选择题（最多 20 题） | 结果页：等级、估计词汇量、参考等级；可以“跳过已经认识的常用词” |
| 回到**看板** | 等级、词汇量卡片有数；技能区块出现语法和词汇两条 |

**判断**：给出的等级和你心里的判断差多少？题目有没有明显有歧义或错误的？

## 4. 背单词

| 做什么 | 应该看到 |
|---|---|
| **背单词** → 选一本词书，设每天新词数 | “今天”显示待复习和新词数 |
| **熟词筛选**：标几个认识 / 不认识 | 认识的以后不会再出现 |
| 复习 / 学新词：翻卡、自评 | 队列减少；看板词书环形图出现“学习中” |
| **我的生词本**：输入一个变形词（如 `went`）加入 | 加进去的是原形 `go` |

## 5. 对话（重点）

用英语聊 8–10 轮，**故意**混几个常见错误（比如 `She like music.`、`I have went there yesterday.`），中间顺便说几件关于自己的事（职业、爱好、学英语的目的）。

| 做什么 | 应该看到 |
|---|---|
| 发消息 | 流式输出；回复先回应内容，再纠正一两处明显错误，不会每个小错都改 |
| 展开回复下的“私教做了什么” | 读了哪些记忆；过几秒出现：记下了哪些事、标了哪些语法错误和用对的语法点 |
| 用中文问一个词怎么说 | 私教回答；这个词被收进生词本（活动里能看到，可以撤回） |
| 在回复里选中一个单词 | 出现“加入生词本” |
| 发一张图片 / 一个 PDF（有配看图模型时） | 先能核对识别出的文字，再发送 |
| 录一段语音（有配转写时） | 转写正确；发送后按文字回复 |
| 点“新对话”，再问 “What do you remember about me?” | 回答用到了前面说过的事 |

**判断**：
- 纠错准不准，有没有把对的改成错的。
- 语法打标（活动里的语法点）对不对。打错的可以在 `/learner` 删掉。
- 记下的事是不是你真的说过的、值得记的。

## 6. 记忆和学习者模型

| 做什么 | 应该看到 |
|---|---|
| **记忆**：看画像、私教记住的事、会话摘要 | 内容和你说的一致；可以修改、删除 |
| 删掉一条记忆，新对话里再问它 | 私教不再知道这件事 |
| **学习者模型**：看语法点 | 你故意犯的错对应的语法点是“薄弱”；展开能看到原句 → 改正、来自哪个对话 |
| 删掉一条打错的证据 | 掌握度重新计算 |

## 7. 看板与学习建议

| 做什么 | 应该看到 |
|---|---|
| 打开**看板** | 图表都有数：词书环形图、语法各级、技能、常错语法点、今天的打卡格 |
| 今天的建议：点“刷新建议” | 生成中 → 出现模型写的建议，标“AI”；刷新按钮进入一小时冷却 |
| 看每条建议 | 标题、理由、实时数字（到期多少个、最近错几次、掌握度）、直达按钮都对得上 |
| 点复习类建议的按钮 | 进到对应页面 |

**判断**：理由写得好不好——像不像一个老师在说话，有没有空话，有没有和实时数字矛盾的地方（理由里不应该写具体数字）。

## 8. 语法练习

| 做什么 | 应该看到 |
|---|---|
| 在建议卡片上点语法练习的“开始练习”（没有这条建议时，从看板“常错语法点”或 `/learner` 语法点详情点“练一练”） | 进入新对话，标题“练习：…”，顶部“语法练习：…”；**私教先开口** |
| 按私教的引导造句，对错都有 | 错了当场改正并说明原因；对了简短肯定、情景逐渐变难 |
| 连续说对五句左右 | 私教小结，问你要继续还是换话题 |
| 还没回话就刷新页面 / 再点一次“练一练” | 回到同一个会话，没有第二段开场白 |
| 看 `/learner` 这个语法点 | 练习里的对错都算进了证据 |

**判断**：开场讲解是否简短、例子是否合适；是不是在引导**你**造句，而不是私教自己一直说；像对话，还是像在出题。

## 9. 其他

| 做什么 | 应该看到 |
|---|---|
| 用导航栏的语言切换改成英文，再切回中文 | 界面文字全部切换；已有练习会话的标题保持创建时的语言；看板上模型写的建议先换成模板文案（语言对得上），距上次生成满 10 分钟后打开看板会按新语言重新生成 |
| **设置 → 用量** | 按天、连接、模型汇总的调用次数、token、错误和延迟；数字随你的使用增加（这张表不按任务区分） |
| **设置 → 显示**：隐藏“私教做了什么” | 对话里不再显示 |

## 反馈格式

每个问题一条，发给我就行：

```
[步骤编号] 做了什么
看到：……
预期：……
截图 / 原文（可选）
```

主观判断的部分（第 3、5、7、8 步的“判断”）写感受即可，例如“建议理由太长、像模板”。
