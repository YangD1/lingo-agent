# 给 Claude Design 的设计提示词

> 用法：把下面“提示词正文”整段复制给 Claude Design（和已经做好的 logo 放在同一个项目里）。设计完成后，按第 8 节导出资源，同步到本仓库，再由开发按资源落地。

---

## 提示词正文

你要为一个开源 Web 应用 **Lingo Agent** 设计完整的视觉系统和主要页面。这个项目里已经有我做好的 **logo**，请以它为品牌起点：主色、辅助色、圆角和整体气质都从 logo 推出来。如果 logo 里有不适合大面积使用的颜色，请给出调整后的版本，并说明理由。

这次只改视觉和布局，**不改功能、信息结构和文案**。页面上每个元素、每种状态都已经在用，请全部保留。文案如果有更好的写法，可以单独列出建议，但设计稿里先用现有文案。

### 1. 产品是什么

- **一句话**：开源的 AI 英语私教，会记住你。界面里的说法是“你的 AI 英语私教：记得你会什么，也记得你总在哪里出错。”
- **用户**：以中文为母语、正在学英语的人，从初学（CEFR A1）到高阶（C2）都有。很多人英语基础弱，看到满屏英文会有压力。
- **核心体验**：
  - 和私教对话。私教记得你的目标、兴趣和常犯的错。
  - 背单词：词书 + FSRS 间隔重复。
  - 入学测：给出 CEFR 定级。
  - 能力看板：图表展示进度。
  - 学习者模型：每个语法点的掌握度和证据。
- **透明是产品的核心价值，不能藏起来**：
  - 每个会调用 AI 的按钮旁都有一个小的“AI”标记，点开能看到会调用哪些模型、每次大约多少 token。
  - 每条私教回复下可以展开“私教做了什么”，列出读了哪些记忆、记下了什么、标了哪些语法错误。
  - 学习者能查看、修改、删除私教记住的一切。
  - 私教提议的改动（换词书、设目标）必须由学习者确认，确认后还能撤销。
- **部署形态**：开源、自部署，可以在很低配的服务器上跑。每个账号在设置里接入自己的模型服务（DeepSeek、OpenAI、Anthropic、通义千问、硅基流动等）。
- **界面语言**：简体中文和英文两套，默认跟随浏览器。两种语言下排版都要好看：中文和英文的字宽、行高不同，数字要等宽对齐。

### 2. 气质与方向

- 像一位耐心、专业、可信赖的私教：温和、安静、专注。不要游戏化的卡通风，不要 Duolingo 式的大色块和吉祥物，也不要冷冰冰的后台管理系统。
- 学习是长期的事，要让人愿意每天打开：信息密度适中，重点清楚，留白充足。
- 对话页是用得最多的页面，要像一个舒服的阅读环境：长时间看英文段落不累，中英混排自然。
- 状态色要成体系：已掌握 / 学习中 / 薄弱 / 未接触、成功 / 警告 / 错误、AI 标记。颜色不能是唯一的信息来源，必须配文字或图形。
- 请同时设计**浅色和深色**两套主题。现在只有浅色，深色要新增，计划提供切换：跟随系统 / 浅色 / 深色。

### 3. 技术约束（设计要能直接落地）

- **前端**：Next.js（App Router）+ Tailwind CSS v4 + shadcn/ui（style `base-nova`，底层是 Base UI）。图表用 Recharts，图标用 **Lucide**（线性图标，14–20px），请继续沿用 Lucide 的风格。
- **颜色**：请用 shadcn 的 CSS 变量命名给出 token，值用 **OKLCH**，浅色、深色各一份：
  - `background` `foreground` `card` `card-foreground` `popover` `popover-foreground` `primary` `primary-foreground` `secondary` `secondary-foreground` `muted` `muted-foreground` `accent` `accent-foreground` `destructive` `border` `input` `ring`
  - `chart-1` … `chart-5`：分类色。现在的分配是 1 = 已掌握，2 = 学习中，3 = 薄弱 / 错误，4 = 熟词跳过，5 = 未学 / 未接触。
  - `sidebar` `sidebar-foreground` `sidebar-primary` `sidebar-primary-foreground` `sidebar-accent` `sidebar-accent-foreground` `sidebar-border` `sidebar-ring`（如果你的导航用侧边栏）
  - 需要新增的语义 token：`success`、`warning`、`ai`（AI 标记专用色）、`heat-0` … `heat-4`（打卡热力图的单色阶）。每个都要有前景色，并说明用在哪里。
  - 现在有几处直接写死了 Tailwind 颜色：AI 标记是 violet，成功和“已掌握”进度条是 emerald，警告和“学习中”是 amber。设计后都要换成 token。
- **字体**：必须是开源、可以自托管的字体（通过 `next/font` 打包，不依赖付费字体，也不能要求访问外网字体服务）。需要：
  - 英文正文 / 标题字体，现在是 Geist。
  - 中文字体。现在没有设置，中文退回系统字体。请给出建议，比如 Noto Sans SC / 思源黑体或 HarmonyOS Sans 一类，并考虑字体文件大小。也可以给“系统字体栈 + 指定英文字体”的方案。
  - 等宽字体，用于模型名、用量表、录音计时，现在是 Geist Mono。
  - 给出字号阶梯、行高、字重。中文正文行高要比英文略大。
- **圆角、间距、阴影**：给出 `--radius` 基准值，以及卡片、按钮、输入框、弹出层各自的圆角、阴影或描边方式。现在卡片用 1px 半透明描边、不用阴影，基准圆角 0.625rem。
- **无障碍**：正文和背景对比度达到 WCAG AA；焦点环清晰可见；可点区域在触屏上至少 40px。
- **不需要位图**：插图和空状态图如果要做，请用简单的 SVG 线稿，和 Lucide 风格一致。也可以不做插图。

### 4. 需要设计的通用组件

请做一张组件表（component sheet），每个组件都给出浅色、深色两版，覆盖常态、悬停、按下、禁用、聚焦：

1. **按钮**：default（主色实心）、outline、secondary、ghost、destructive（现在是浅红底，不是实心红）、link。尺寸 xs / sm / default / lg，以及只有图标的按钮。
2. **卡片**：标题、描述、右上角操作、内容、底部，另有紧凑尺寸。
3. **表单**：输入框、多行文本框、原生下拉框、带候选的输入框（autocomplete，候选项用等宽字体）、复选框、单选、滑块、数字输入。
4. **分段切换**：比如“多说中文 / 多说英文”。
5. **弹出层（popover）**：单词气泡、AI 标记说明、朗读设置都用它。
6. **AI 标记**：一个很小的“AI”胶囊（约 16px 高，10px 字），贴在按钮右上角或紧跟在后面。悬停或点按弹出说明：功能描述、每次模型调用一行（任务名、时机、“约 X 输入 + Y 输出 token”、模型名、估计来源），底部一句“只显示 token 数，价格取决于你的模型服务商。”它到处都有，所以必须**存在感低但一眼认得出**。
7. **页内提示条（banner）**：浅底、带说明文字、主按钮和关闭按钮。比如“先做个入学测吧……”“开始入学测”。
8. **行内状态文字**：成功（如“已保存。”）、警告（如词汇量估计不可靠）、错误（如“连不上服务器……”）。
9. **快捷回复胶囊（chips）**：右对齐、可多个换行。
10. **标签 / 徽标**：CEFR 等级（A1–C2）、“当前”、“新词”、“生词本”。可以考虑给 CEFR 六个等级一套有顺序感的颜色或样式。
11. **进度条**：细条，用于词书进度和语法掌握度（薄弱 / 学习中 / 已掌握三色）。
12. **表格**：用量表有 8 列，带合计行，窄屏横向滚动；数字列右对齐、等宽。
13. **列表行**：带分隔线的列表，左侧主信息、次要信息一行、右侧操作。
14. **可折叠行**：左侧 chevron，展开后显示证据列表。
15. **确认方式**：现在用浏览器原生的确认框，以及按钮原地变成“确定 / 取消”。如果你设计了对话框（dialog），请一并给出。
16. **加载、空状态、错误状态**：现在只有文字（“加载中…”）。请给出骨架屏或更好的样式，以及空状态的写法。

### 5. 应用外壳与导航

- **现状**：顶部一行，左边产品名，中间 7 个纯文字导航，右边用户名、语言选择、退出登录。导航没有图标、没有当前页高亮，窄屏会溢出。
- **导航项（按顺序）**：看板、对话、背单词、记忆、学习者模型、入学测、设置。
- **后续会新增的页面，请预留位置**：阅读（分级新闻）、写作（批改）、练习（多题型）、口语 / 跟读、每日计划。导航结构要能从 7 项扩到 12 项左右。
- **要求**：
  - 桌面端给出导航方案（左侧栏或顶栏，你来判断并说明理由），要有图标、当前页高亮，以及用户区（昵称、语言切换、主题切换、退出）。
  - **移动端**（390px 宽）要能用：给出移动端导航，比如底部标签栏放最常用的 4–5 项，其余收进“更多”。
  - logo 放在导航里，并给出小尺寸（favicon、移动端）用法。

### 6. 页面清单（每页都要设计）

下面括号里的文字都是界面上的真实文案。

#### 6.1 首页 `/`（未登录）
- **现状**：一个居中标题“Lingo Agent”、一句标语、“登录”“注册”两个按钮，右上角语言选择。
- 请设计成一个简洁的产品首页：标语、3–4 个核心卖点（会记住你的私教；语法跟踪与掌握度；FSRS 背单词；入学测定级；透明：AI 做了什么都看得见；自带模型、开源自部署），以及登录 / 注册入口。不要放虚构的用户评价或数据。

#### 6.2 登录 / 注册
- 居中一张卡片，右上角语言选择。
- 登录：“登录”，“欢迎回来，从上次停下的地方继续。”，字段“邮箱”“密码”，按钮“登录”，底部“还没有账号？去注册”。
- 注册：“创建账号”，“开始和你的 AI 私教练习英语。”，字段“邮箱”“昵称（可选）”“密码”（提示“至少 8 个字符。”），按钮“注册”。
- 错误显示在按钮上方，比如“邮箱或密码不正确。”

#### 6.3 看板 `/dashboard`（登录后的首页，最重要的页面之一）
- **标题**：“能力看板”。
- **四个数字卡**（桌面 4 列、手机 2 列），每张是小标签 + 大数字 + 一行说明：
  - “CEFR 等级”：如 B1，或“未评估”加“做入学测”链接。
  - “估计词汇量”：“约 4200 词”。
  - “连续学习”：“5 天”，说明为“今天已学习 / 今天还没学，别断了”。
  - “今日待复习”：“12 个词”。
- **“今天的学习”卡**（整宽）：里面嵌了一个完整的对话框（约 512px 高），见 6.4。
  - 还没开始聊时：左边一个私教问候气泡（“今天有 12 个词到期，想先做什么？”），右边一组快捷回复胶囊（“今天学什么？”“帮我复习到期的 12 个词”“我想练一下一般过去时”……）。
  - 没配置模型时：一行提示“还没配置模型，下面是按规则给出的建议。去设置”，下面是 3 列建议卡。每张建议卡有标题、原因、依据（如“到期 12 个”）、主按钮（“去复习”）、AI 标记和“查看依据”链接。
  - 右上角在有对话时显示“在对话页继续”。
- **2×2 图表卡**（手机 1 列）：
  - “词书进度”：环形图，分已掌握 / 学习中 / 熟词跳过 / 未学，中心显示百分比，下方图例和一句总结。
  - “技能估计”：横向条形图，刻度 A1–C2；下方六行：语法、词汇、听力、口语、阅读、写作，没测过的显示“未评估”。
  - “语法掌握”：横向堆叠条形图，每行一个 CEFR 等级，分已掌握 / 学习中 / 薄弱 / 未接触；下方一个小数字表。
  - “常错语法点”：横向条形图（错误色）；下方有序列表，每行是语法点名称（链接）、“3 次”、“练一练”链接、AI 标记。
- **“学习打卡”卡**（整宽）：GitHub 式日历热力图，最近 12 周，每天一格（单色 5 阶），图例“少 ▢▢▢▢▢ 多”，下方一句总结。
- 每张图都有空状态文字，比如“还没选词书。去选一本”。

#### 6.4 对话 `/chat`（最常用，请做得最细）
- **布局**：左侧会话列表（约 256px），右侧对话区，内容最大宽约 768px 居中。移动端会话列表要能收起（抽屉）。
- **会话列表**：
  - 顶部按钮“新对话”。
  - 每行显示标题（或“新会话”）；三种特殊会话前面有小图标：语法练习（靶心）、学习规划（指南针）、今天的学习（太阳）。
  - 当前行高亮，悬停时出现删除图标。
- **对话区顶部可能出现的条**：
  - 入学测提示条：“先做个入学测吧：大约 10 分钟，私教会按你的水平调整讲解和练习。”+“开始入学测”+关闭。还有“继续”“重新测试”两种变体。
  - 练习条（练习会话专用）：“语法练习：一般过去时 · A2”+“查看依据”。
- **消息**：
  - 用户消息靠右，主色底。
  - 私教消息靠左，浅底，渲染 Markdown：段落、列表、标题、引用、代码、表格、链接。
  - 空会话居中提示“用英语随便说点什么，我会回复你，并顺便指出错误。”
  - 流式输出中显示跳动的“…”。
  - 停止后附一行小字“已停止，这段未完成的回复不会保存。”
  - 出错时在气泡里显示红字。
- **消息里的附件**：图片缩略图；语音消息（音频播放条）；文档卡片（文件图标、文件名、大小、下载）。
- **私教回复下方的工具行**（小字）：
  - “朗读”（读的时候变成“停止”）。
  - 齿轮“朗读设置”，弹出朗读设置面板，见 6.12。
  - “看中文 / 看英文 / 看原文”，加 AI 标记。
  - 偶尔出现提示：“这台设备没有中文朗读声音，只读英文部分。”或“在线声音没有出声……已改用本机的声音朗读。”
- **私教卡片**（出现在回复下方，带左侧图标）：
  - 提议卡（换词书、设目标）有四种状态，都要设计：
    - 待确认：“确认”“不用了”，加一行“你确认之前不会有任何改动。”
    - 已执行：成功色“已完成。”加“撤销”。
    - 已拒绝：“你没有采纳这条建议。”
    - 已撤销：“已撤销，恢复成原来的设置。”
  - 练习卡：“练习 一般过去时”+“开始练习”+AI 标记。
  - 跳转卡：标题、实时状态（如“待复习 12 个 · 今天还剩 5 个新词”）、按钮（“去复习”）。
- **“私教做了什么”**（每条回复下一行可折叠的小字）：
  - 折叠时：“私教做了什么：读取 3 条记忆 · 记下 1 条 · 标记 2 个语法错误 · 收进生词本 1 个词”。
  - 展开后分段列出：读取的记忆、记下的内容、语法错误（原文加删除线 → 改正后的写法 · 语法点链接）、收进生词本的词（每个可“移出”）。
  - 底部链接：“管理记忆”“查看学习者模型”“不再显示”。
  - 失败时一行说明，比如“……失败了，这一轮先跳过。”
  - 这一块信息量大，但要安静、不抢正文。
- **单词气泡**：私教回复里的每个英文单词都可以悬停 0.3 秒或点按，弹出约 320px 宽的气泡。单词在正文里只有很淡的可交互暗示。气泡内容：
  - 单词（加粗）、/音标/、朗读图标。
  - “原形 go”（按原形匹配时）。
  - 最多 3 行中文释义。
  - “原句”：这个词所在的句子，词本身加粗。
  - “AI 例句”按钮加 AI 标记，展开后是英文句子，下面是灰色的中文翻译。
  - 底部“加入生词本”，加入后变成“已加入生词本。”或“已在生词本。”
- **输入区**：
  - 上方一行“私教说：[多说中文 | 多说英文] 从下一句开始生效”。
  - 附件托盘：每个附件一个小卡片，有缩略图或图标、文件名、处理状态（“上传中…”“正在转写…”“第 2 / 5 页”“已识别”）、重试、编辑、移除。编辑时展开一个可以修改识别文字的编辑框。
  - 输入行：左边竖排两个图标按钮“添加图片、文档或音频”“录制语音消息”（各带 AI 标记），中间是多行输入框（“输入消息…（Enter 发送，Shift+Enter 换行）”），右边是“发送”（带 AI 标记，流式输出时变成“停止”）。
  - 录音中：输入框变成状态条，有红色跳动圆点、“0:12 / 3:00”（等宽）、音量电平、“正在录音…”、“放弃”。录音按钮变成红色停止按钮。
  - 拖文件进来时，整个对话区出现虚线框“松开即可添加附件”。

#### 6.5 入学测 `/placement`
- 单列，最大宽约 672px。
- **介绍卡**：“入学测”，说明约 10 分钟、分两部分（词汇最多 40 题，语法最多 20 题），一句“不会就选最像的，不显示对错。可以随时离开，回来接着做。”，按钮“开始”。
- **词汇题**：进度“第一部分 · 词汇 · 第 12 / 40 题”，“你认识这个词吗？”，一个很大的英文单词居中，两个大按钮“不认识 / 认识”，键盘提示“键盘：Y 认识，N 不认识”。
- **语法题**：进度“第二部分 · 语法 · 第 3 题（最多 20 题）”，“选出填入空白处的正确选项”，句子（有空格），四个整宽选项按钮“1.”–“4.”，键盘提示。
- **结果页**，四张卡：
  - “测试结果”：大号等级（如 B1），两个小格（“语法”等级和题数；“估计词汇量 约 4200 词”）；词汇量估计不可靠时显示警告。
  - “接下来做什么”：嵌入对话框（同 6.4），空状态居中放“和私教聊聊这次结果”（加 AI 标记）。
  - “跳过已经认识的常用词”：“当前词书里有 860 个常用词……”+“把这 860 个词标为已认识”，完成后显示“撤销”。
  - “重新测试”：按钮点击后原地变成“确定重新测试 / 取消”。

#### 6.6 背单词 `/vocab`
- “今天”卡：当前词书；“待复习 12 个 · 新词还剩 5 个（今天已开始 15 / 20）”；按钮“开始”（主按钮），以及“只学新词”“熟词筛选”“我的生词本”。
- “词书”卡：词书列表（牛津 3000、中考、高考、四级、六级、考研、雅思、托福、GRE），每行是名称、词数、细进度条和“学习中 120 · 已认识 860 · 已接触 31%”，右边是“当前”标签或“学这本”按钮。
- “每天新词数”卡：一个数字输入框加“保存”。

#### 6.7 复习卡片 `/vocab/review`（专注模式）
- 顶部“已复习 8 · 还剩 4”和“回到背单词”。
- 卡片居中：标签（“新词”“生词本”），大号单词加朗读按钮。正面是“显示答案”；翻面后显示音标、中文释义和英文释义（灰色）。
- 评分 4 个按钮：“忘了 / 模糊 / 记得 / 很熟”，各带快捷键数字 1–4。提示“空格显示答案 · 1–4 评分”。
- 完成页：“这一轮完成：复习了 12 张。……”
- 这一页要有沉浸感，可以考虑弱化导航。

#### 6.8 熟词筛选 `/vocab/screen`
- 单词方块网格（手机 2 列，平板 3 列，桌面 5 列），点一下标为认识，选中时用主色填充。
- 底部“已标记认识 23 / 50”和“好了，提交”。
- 结果：“这批 50 个词里你认识 23 个。”，按钮“下一批”“回到背单词”。

#### 6.9 我的生词本 `/vocab/mine`
- 添加框：带候选的输入框（“输入英文单词，比如 reluctant”）加“添加”。
- 列表每行：单词、/音标/、第一行释义（灰色，截断），以及一行“对话中收集 · 学习中 · 下次复习 3 天后”，右边“删除”。
- 空状态、“显示更多（还有 20 个）”。

#### 6.10 学习者模型 `/learner`
- “语法掌握度”卡：
  - 说明掌握度怎么算；各等级覆盖率小字（“A1 接触 12/18”）。
  - 两个筛选：等级、状态。
  - 每个语法点一行：名称加 CEFR、掌握度小条（薄弱 / 学习中 / 已掌握三色）、“62% · 学习中”、计数“错误 3 次 · 自由表达用对 5 次 · 做题答对 2 次”。
  - 展开后：“和私教练一练”（AI 标记），以及证据列表：入学测答对 / 答错、“用对了”、原文删除线 → 改正；还有错误类型、严重程度、来源链接、删除图标。
- “技能估计”卡、“删除所有学习记录”卡（危险操作）。

#### 6.11 记忆 `/memory`
- “你的画像”卡：表单两列。
  - 字段：母语、职业、目标考试、语法讲解语言、私教说话（按等级 / 多说中文 / 多说英文）、每天学习分钟数、时区（加“用本机时区”）、兴趣、学英语的目的。
  - 一行提示：“你在这里保存的字段以你为准：私教不会再根据聊天内容修改它们。”
  - 按钮“保存画像”“放弃修改”。
- “私教记住的事”卡（标题带 AI 标记）：添加框（“例如：我十月底有一场面试。”+“记住这条”）；每条事实可编辑、删除，下方小字显示日期和来源会话；“忘掉全部事实”。
- “会话摘要”卡：只能删除；“删除全部摘要”。

#### 6.12 设置 `/settings`
- “模型连接”卡：
  - 每个连接是一个框：名称、类型、地址、“密钥 sk-…ab”、最近测试状态；“默认模型”是等宽的带候选输入框，加“保存模型”“测试”和测试方式下拉；还有“编辑”“删除”。测试结果用成功或错误色显示。
  - 下方“添加连接”表单：服务商下拉（预设加“自定义”）、名称、API 类型、Base URL、API 密钥。
- 四张“模型顺序”卡：对话模型、后台整理模型、看图模型、语音转文字。
  - 每张显示当前顺序（编号列表，等宽 `连接:模型`），按钮“调整顺序”“恢复默认”。
  - 编辑时每行是连接下拉、模型输入、上移、下移、移除，还有“+ 添加备用模型”。
- “显示”卡：复选框“在私教回复下显示‘私教做了什么’”。
- “朗读”卡：
  - 英文口音（美音 / 英音）单选。
  - 英文声音、中文声音下拉，第一项是“自动（当前：某声音）”，每个后面跟“试听”按钮。播不出声的声音标“（这台设备上播不出声）”。
  - 英文语速滑块，显示“0.9×”。
  - 几行提示。
  - 同一个面板也会出现在对话页的弹出层里，宽约 320px，要能塞得下。
- “用量”卡：时间范围下拉、刷新，加 8 列表格（日期、模型、调用次数、输入 token、输出 token、错误、回退、平均延迟），带合计行。
- 建议：设置页内容多，可以考虑加页内目录或分组标签。

### 7. 交付物

请按以下顺序给出：

1. **设计方向说明**：一段话。说明从 logo 推出了什么，整体气质怎么体现。
2. **Design tokens**：
   - 浅色、深色两套 CSS 变量表（名称按第 3 节，值用 OKLCH，并附十六进制参考）。
   - 字体方案和字号阶梯。
   - 圆角、间距、阴影或描边规则。
   - 图表配色（chart-1…5、heat-0…4），浅色、深色都要能区分，色弱用户也能区分。
3. **组件表**：第 4 节所有组件，浅色、深色。
4. **页面设计稿**，桌面 1440px 和手机 390px 两个尺寸：
   - 必做：首页、登录、看板（有数据和全空两种状态）、对话（含单词气泡、“私教做了什么”展开、提议卡四种状态、录音中、附件托盘）、复习卡片、学习者模型、设置。
   - 其次：入学测（题目和结果）、背单词、熟词筛选、生词本、记忆。
   - 深色至少做：看板、对话。
5. **导航方案**：桌面和移动端，以及扩到约 12 项时的样子。
6. **logo 用法**：导航里的尺寸、favicon、深色背景下的版本。

### 8. 导出要求（方便开发直接用）

设计完成后，请把以下内容整理成可下载的资源：

- `tokens.css`：`:root` 和 `.dark` 两段 CSS 变量，名称和第 3 节一致，值用 OKLCH，可以直接替换 shadcn 的 `globals.css`。
