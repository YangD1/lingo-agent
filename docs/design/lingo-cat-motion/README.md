# Lingo 猫咪动画 · 六种情绪

用法：把 `lingo-cat.css` 替换掉之前的 `loader.css`，把 `LingoCat.tsx` 放进 components。旧的 `LingoLoader` 仍然能用，它现在是 `<LingoCat />` 的别名。

| mood | 名字 | 用在哪里 | 播放方式 |
| --- | --- | --- | --- |
| `loader`（默认） | 加载 | 通用加载：页面、卡片、列表第一次拉数据 | 循环，2.4s 一圈 |
| `hop` | 跳跳 | 要等好几秒的操作：入学测出结果、生成学习计划、批改写作、导入词书。可以配进度条 | 循环，1.6s 一圈 |
| `ai` | 星星飞出 | AI 正在生成：私教回复前、AI 例句、看中文翻译 | 循环，2.4s 一圈 |
| `done` | 完成 | 复习一轮结束、入学测做完、打卡成功 | 只播一次，约 1.4s，结束时停在静态 logo |
| `idle` | 待机 | 空状态和等待输入：新对话空白页、生词本为空、看板还没数据 | 循环，4.8s 一圈，很安静 |
| `oops` | 出错 | 连不上服务器、模型调用失败、上传失败 | 只播一次，1.2s，停在耳朵耷拉的姿势 |

## 注意

- **重播一次性动画**：`done` 和 `oops` 只播一次。想再播，给组件换一个 `key`，例如 `<LingoCat key={n} mood="done" />`。
- **跳起来会超出方框**：`hop` 和 `done` 会往上跳约 16px，超出 SVG 的方框。外层容器不要设 `overflow: hidden`，或者在上方留出约 16% 的空间。`svg/` 文件夹里的单文件版本已经把画布往上加高了，可以直接用 `<img>` 引用。
- **小尺寸**：`size ≤ 24` 时自动切换成小号版，只动尾巴和星星（`hop` 保留上下跳）。
- **减少动态效果**：系统开了“减少动态效果”时：
  - 循环的几种只剩星星缓慢明暗变化；
  - `done` 直接显示静态 logo；
  - `oops` 显示灰色星星。
- **等待时间**：建议等待超过 300ms 再显示 `loader`、`hop`、`ai`，避免一闪而过。
- **颜色**：`lingo-cat.css` 依赖这几个 token：`--brand`、`--spark`、`--foreground`、`--muted-foreground`。
