# Lingo Agent · 视觉系统交付包

## 设计方向

设计从猫咪 logo 出发。

- **主色**：珊瑚橙是品牌色，但它太亮，白字放上去对比度只有 3.3:1。所以界面主色压深一档，用陶土珊瑚 `#C8441F`，白字对比度 4.9:1。亮珊瑚 `#F25C3B` 只用在 logo 和小面积点缀上。深色主题反过来，用亮珊瑚 `#FF7A5C` 做主色，配深色字。
- **文字与底色**：logo 的墨色 `#1C1B22` 做正文色。底色是带一点暖意的米白，看起来像纸。
- **圆角**：取自猫咪的圆润造型，基准 12px，卡片 16px，快捷回复是胶囊形。
- **AI 标记**：用 logo 里的四角星做图标。颜色选了冷靛蓝，在暖色界面里一眼能认出来，又不会和琥珀色的警告混淆。
- **整体气质**：全站只有一个强调色，用细描边、不用阴影，留白充足。目标是安静、温和、专注，像一位耐心的私教。猫只出现在 logo 和私教头像里，不做吉祥物。

## 对现状的改动建议（不涉及功能）

1. **AI 标记**：现在写死的 `violet` 换成 `ai` token；`emerald` 换成 `success` / `chart-1`；`amber` 换成 `warning` / `chart-2`。
2. **导航**：桌面改成可折叠的左侧栏；手机改成底部标签栏，加一个“更多”面板。对话页侧栏默认收成图标栏。
3. **确认**：不可恢复的删除操作改用对话框，可撤销的操作继续用原地确认。
4. **深色主题**：用 `next-themes`（`attribute="class"`），提供“跟随系统 / 浅色 / 深色”三档。

## 文案

设计稿用的都是现有文案。有几处 brief 没给出原文，设计稿里写了占位文字，请以代码里的现有文案为准：

- 数字卡的说明行
- 入学测“继续”“重新测试”两种提示条的说明
- 词汇量估计不可靠时的警告
- 复习完成页省略号后面的内容

可选的文案建议：

- 产品名在界面里统一写 “Lingo Agent”。logo 图形旁的文字可以继续用小写 “lingo-agent”，但同一屏里只用一种写法。
- 空状态统一成两句：一句“现在是什么情况”，一句“做什么会变好”。例如“还没选词书 / 选一本词书，私教会按它安排每天的新词。”
