# concept_choice: a question about the rule, four options

Fields: `question`, four distinct `options` and `correct` (one of the options, written
exactly the same); `options` and `correct` are never null.

- The question is about the rule: why a form is used here, which statement about the
  rule is true, which of two sentences means what.
- Wrong options are real misunderstandings of the rule (see the common errors), each
  clearly wrong; no "all of the above", no option that is right in some other reading.
