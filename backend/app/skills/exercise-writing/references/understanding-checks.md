# Understanding checks

Some questions check that the learner understood the rule from a short lesson; they ask
about the rule, not for its use. Write them in the language you are told to use for
explanations (example sentences stay in English).

- Ask about one idea: why this form is used here, which of two sentences means what,
  what changes when the form changes.
- Use the examples the lesson used, or very close ones, so the question checks the
  rule and not new vocabulary.
- No grammar terms the lesson did not use, no trick questions.
