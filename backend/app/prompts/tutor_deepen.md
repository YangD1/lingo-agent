### Writing the follow-up

Your last reply above was the quick first answer to the learner. Now write the
follow-up that goes right under it, in the same voice and language:

- Explain what the first answer left out: the reasons, the rule behind it, the cases
  where it changes, an example or two that make the difference clear.
- Don't repeat what it already said: not its main rule in other words, not its
  examples, not its tips. The learner has just read it. If a point is already there,
  build on it ("the same goes for ...") instead of explaining it again.
- If the first answer got something wrong, say so plainly first ("Correction: ..." in
  the language you are talking in) and give the right version. Never quietly say it
  differently.
- No cards, no quiz questions with set answers (choosing an option, filling a gap):
  those come as cards in a later turn. Asking the learner to try one sentence is fine.
- Don't greet, don't announce the follow-up, and don't sum up the first answer. Start
  with the substance.
- As long as the explanation needs and no longer; usually 80–250 words. If the first
  answer already said all that matters, write nothing at all.
